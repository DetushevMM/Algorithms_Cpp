# Школьная сеть — проверка связности графа

## Условие задачи

В школе установлено N компьютеров. Некоторые пары компьютеров соединены напрямую сетевыми кабелями. Данные могут передаваться не только напрямую, но и через промежуточные компьютеры.

Системный администратор хочет проверить, можно ли передать файл с любого компьютера на любой другой. Определите, является ли школьная компьютерная сеть связной.

Формат ввода
```
· Первая строка: два целых числа N и M — количество компьютеров и количество соединений.
· Следующие M строк: пары u v — компьютеры u и v соединены напрямую.
```
Формат вывода
```
· YES — если файл можно передать с любого компьютера на любой другой.
· NO — в противном случае.
```
Ограничения
```
· 1 ≤ N ≤ 1000
· 0 ≤ M ≤ 5000
· Соединения двусторонние, петель и кратных соединений нет.
```
---

## Идея решения

Сеть компьютеров — это неориентированный граф, где:
- вершины — компьютеры,
- рёбра — сетевые кабели.

Сеть связна тогда и только тогда, когда из любой вершины достижимы все остальные. Достаточно запустить обход из одной вершины (например, из вершины 1) и проверить, что посещены все N вершин.

Если после обхода count == N → YES, иначе → NO.

---

## Две реализации обхода

В решении используются два классических алгоритма обхода графа: DFS и BFS. Оба дают одинаковый результат, но отличаются порядком обхода и внутренней структурой данных.

**DFS — поиск в глубину**

- Использует стек (LIFO — last in, first out).
- Идёт «вглубь»: из текущей вершины переходит к первому непосещённому соседу, пока может, затем возвращается назад.
- Реализован итеративно через std::vector<int> в роли стека: push_back / pop_back.
- Порядок обхода: «одна ветка до конца, потом следующая».

**BFS — поиск в ширину**

- Использует очередь (FIFO — first in, first out).
- Идёт «вширь»: сначала посещает всех соседей текущей вершины, потом соседей соседей и т.д.
- Реализован через std::vector<int> в роли очереди с индексом head (голова очереди), без удаления элементов из начала.
- Порядок обхода: «волнами» по уровням удалённости от стартовой вершины.

Ключевой момент для обоих алгоритмов

Вершину помечаем посещённой (visited[u] = true) сразу при добавлении в стек/очередь, а не при извлечении. Это гарантирует, что каждая вершина попадёт в структуру ровно один раз.

---

**Отличия DFS и BFS**

|Характеристика| DFS| BFS|
|--------------|----|----|
Структура данных| Стек (LIFO)| Очередь (FIFO)
Порядок обхода| Вглубь, по ветке| Вширь, по уровням
Реализация| push_back / pop_back| push_back / индекс head
Память в худшем случае| O(N)| O(N)
Типичное применение| Связность, циклы, топосортировка| Кратчайшие пути в невзвешенном графе

Для задачи проверки связности оба алгоритма эквивалентны.

## Оценка сложности

Для обеих реализаций:
- Время: O(N + M) — каждая вершина обрабатывается один раз, каждое ребро просматривается один раз (в неориентированном графе — дважды, по одному на каждую конечную вершину).
- Память: O(N + M):
  - O(N + M) — список смежности,
  - O(N) — массив visited,
  - O(N) — стек/очередь в худшем случае.

Такая сложность оптимальна: чтобы проверить связность, граф нужно как минимум прочитать целиком.

---

**Почему выбрали std::vector**

1. Список смежности (std::vector<std::vector<int>>) — самый эффективный способ хранить разреженный граф. По сравнению с матрицей смежности N × N (до 10⁶ ячеек) он занимает O(N + M) памяти, что при N ≤ 1000, M ≤ 5000 даёт значительную экономию.
2. Удобство итерации — цикл for (int u : adj[v]) читается проще, чем ручной обход связного списка (forward-star) с массивами head / next / to.
3. Динамический размер — не нужно заранее знать степени вершин, как при использовании std::array.
4. Стек и очередь — std::vector с push_back (и индексом head для очереди) работает за амортизированное O(1) на операцию и не требует подключения <stack> / <queue>.
5. Совместимость с ограничениями — при N ≤ 1000 рекурсивный DFS тоже был бы безопасен, но итеративные версии универсальнее и не зависят от размера стека вызовов.

---

Граничные случаи· N = 1, M = 0 — одна вершина, граф связный → YES.
- M = 0, N > 1 — все вершины изолированы → NO.
- Несвязный граф с несколькими компонентами → NO.
- Граф с циклом, но связный → YES (алгоритм корректно обрабатывает циклы за счёт массива visited).

---

### Пример

Ввод:
```
4 3
1 2
2 3
3 4
```
Вывод: YES

Ввод:
```
4 2
1 2
3 4
```
Вывод: NO

# HeapSort — пирамидальная сортировка

1. Задача

- Реализовать алгоритм HeapSort — пирамидальную сортировку.
- Исходный массив необходимо отсортировать по невозрастанию, то есть от большего числа к меньшему.

Например:
```
66
53
24
11
-11
-25
-28
-62
-90
-92
```
---

2. Как работает HeapSort

- HeapSort использует структуру данных бинарная куча (Heap).
- В этой реализации используется максимальная куча (Max-Heap): «каждый родитель больше или равен своим детям.»
- Куча хранится непосредственно в обычном массиве.
```
Для элемента с индексом "i":

левый ребёнок  = 2 * i + 1
правый ребёнок = 2 * i + 2
родитель       = (i - 1) / 2

Например:

Массив:

[66, 53, 24, 11, -11, -25, -28]

Индексы:

  0   1   2    3    4    5    6
 66  53  24   11  -11  -25  -28

Представление в виде дерева:

             66
           /    \
         53      24
        /  \    /  \
      11  -11 -25  -28

Здесь "66" находится в корне и является максимальным элементом.
```
---

3. Основная функция ShiftDown

"ShiftDown" восстанавливает свойство максимальной кучи, если элемент оказался меньше одного из своих детей.

Алгоритм:

1. Считаем текущий элемент самым большим.
2. Сравниваем его с левым ребёнком.
3. Сравниваем результат с правым ребёнком.
4. Находим наибольший элемент из трёх.
5. Если ребёнок оказался больше родителя — меняем их местами.
6. Продолжаем просеивание вниз.
```
void ShiftDown(int* array, int n, int m) {
  int bigger = m;
  int left = 2 * m + 1;
  int right = 2 * m + 2;

  if (left < n && array[left] > array[bigger]) {
    bigger = left;
  }

  if (right < n && array[right] > array[bigger]) {
    bigger = right;
  }

  if (bigger != m) {
    Swap(array[m], array[bigger]);
    ShiftDown(array, n, bigger);
  }
}
```
Почему сравниваем именно с большим ребёнком?
```
Допустим:

       5
      / \
    10   7

Оба ребёнка больше "5", но менять местами нужно именно с "10":

       10
      /  \
     5    7

Если поменять "5" с "7", получится:

       7
      / \
    10   5
```
и свойство Max-Heap всё ещё будет нарушено.

---

4. Две фазы HeapSort

Алгоритм состоит из двух основных этапов:

1. Построить Max-Heap
2. Последовательно переносить максимум в конец массива

---

5. Фаза 1 — построение Max-Heap
```
for (int i = n / 2 - 1; i >= 0; --i) {
  ShiftDown(array, n, i);
}
```
Почему начинаем с "n / 2 - 1"?

Элементы начиная с индекса "n / 2" являются листьями. У них нет детей, поэтому просеивать их не нужно.

Например: [4, 10, 3, 5, 1]
```
Дерево:

         4
       /   \
     10     3
    /  \
   5    1
```
Последний внутренний узел имеет индекс: `n / 2 - 1 = 5 / 2 - 1 = 1`

Поэтому обработка идёт:
```
i = 1
i = 0
```
То есть снизу вверх.
```
После обработки всего массива получаем Max-Heap:

        10
       /  \
      5    3
     / \
    4   1
```
Массив: [10, 5, 3, 4, 1]

Сложность

Построение кучи выполняется за: O(n)

Это важный момент: построение Heap не требует "O(n log n)".

---

6. Фаза 2 — сортировка

После построения Max-Heap максимум всегда находится в: array[0]

Поэтому выполняем:
```
for (int i = n - 1; i > 0; --i) {
  Swap(array[0], array[i]);
  ShiftDown(array, i, 0);
}
```
На каждом шаге:

1. Меняем максимум с последним элементом [10, 5, 3, 4, 1].

После: [1, 5, 3, 4, 10]. "10" теперь находится на своём окончательном месте.

2. Уменьшаем размер кучи

Теперь "10" больше не является частью кучи.
```
Куча:       [1, 5, 3, 4]
Отсортировано: [10]
```
3. Восстанавливаем Max-Heap

### ShiftDown(array, i, 0);

Получаем: [5, 4, 3, 1, 10]

Затем процесс повторяется.

В результате HeapSort формирует массив по возрастанию: [-92, -90, -62, -28, -25, -11, 11, 24, 53, 66]

---

7. Почему вывод выполняется с конца

По условию требуется сортировка по невозрастанию:
```
66
53
24
11
-11
-25
-28
-62
-90
-92
```
Но Max-Heap в процессе HeapSort помещает максимальные элементы в конец.

Поэтому после "HeapSort" массив находится в порядке: [-92, -90, -62, -28, -25, -11, 11, 24, 53, 66]. Чтобы получить требуемый порядок, массив просто выводится справа налево:
```
for (int i = n - 1; i >= 0; --i) {
  std::cout << array[i] << '\n';
}

То есть:

HeapSort:
[-92, -90, -62, -28, -25, -11, 11, 24, 53, 66]
                                                    ↑
                                               максимум
```
Вывод с конца: 66, 53, 24, 11, -11, -25, -28, -62, -90, -92

Использование Max-Heap с последующим обратным выводом позволяет не реализовывать отдельную Min-Heap.

---

8. Полный алгоритм
```
Исходный массив
       │
       ▼
Построить Max-Heap
       │
       ▼
Максимум находится в array[0]
       │
       ▼
Поменять array[0] с последним
       │
       ▼
Уменьшить размер кучи
       │
       ▼
ShiftDown(array, новый размер, 0)
       │
       ▼
Повторять до тех пор,
пока в куче не останется один элемент
       │
       ▼
Получить сортировку по возрастанию
       │
       ▼
Вывести массив с конца
       │
       ▼
Невозрастающий порядок
```
---

11. Сложность

|Операция| Сложность|
|--------|----------|
Построение Max-Heap| "O(n)"
Один "ShiftDown"| "O(log n)"
Основной этап сортировки| "O(n log n)"
HeapSort целиком| "O(n log n)"
Дополнительная память| "O(log n)" из-за рекурсии

Сама сортировка выполняется на месте — дополнительный массив для сортировки не создаётся.

---

12. Основные функции

### "Swap"

Меняет местами два элемента: `void Swap(int& a, int& b)`

### "ShiftDown"

Восстанавливает свойство Max-Heap начиная с указанного элемента: `void ShiftDown(int* array, int n, int m)`, где:
- "array" — массив;
- "n" — текущий размер кучи;
- "m" — индекс элемента, который необходимо просеять вниз.

### "HeapSort"

Выполняет всю сортировку: `void HeapSort(int* array, int n)`

Внутри:

1. строится Max-Heap;
2. максимум переносится в конец;
3. размер кучи уменьшается;
4. выполняется "ShiftDown";
5. процесс повторяется.

---

13. Важная особенность реализации

Параметр "n" в "ShiftDown" — это не обязательно размер всего массива.

Во время сортировки массив логически разделён на две части:
```
[        КУЧА        ][ ОТСОРТИРОВАННАЯ ЧАСТЬ ]
          n                    n+...
          ↑
    граница кучи
```
Например:
```
[5, 4, 3, 1, 10, 20, 30]
<------ heap ------><sorted>
```
Здесь "10", "20", "30" уже не должны участвовать в работе "ShiftDown".

Поэтому вызывается: `ShiftDown(array, i, 0);`, где "i" постепенно уменьшается. Это позволяет выполнять сортировку непосредственно внутри исходного массива.

---

14. Итог

В данной реализации:
- используется Max-Heap;
- куча хранится в обычном массиве;
- "ShiftDown" восстанавливает свойство кучи;
- сначала строится Max-Heap за "O(n)";
- затем максимумы последовательно переносятся в конец;
- итоговая сортировка выполняется за "O(n log n)";
- дополнительная память для массива не требуется;
- поскольку HeapSort формирует массив по возрастанию, для получения невозрастания результат выводится с конца к началу.

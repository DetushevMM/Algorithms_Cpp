# Подсчет количества ребер неориентированного графа

## Условие задачи

Простой неориентированный граф задан матрицей смежности. Найдите количество ребер в графе.

Формат входных данных
- В первой строке число N — число вершин в графе (1 ≤ N ≤ 100), затем матрица смежности — N строк по N чисел, каждое из которых равно 0 или 1.

Формат выходных данных
- Выведите количество ребер заданного графа.

Пример

|стандартный ввод| стандартный вывод|
|----------------|------------------|
3 0 1 1 1 0 1 1 1 0| 3

---

## Идея решения

Ключевое наблюдение

Матрица смежности неориентированного графа обладает свойством симметричности относительно главной диагонали: `A[i][j] = A[j][i]`

Это означает, что если между вершинами i и j существует ребро, то в матрице ему соответствуют две единицы:
```
· A[i][j] = 1
· A[j][i] = 1
```
Дополнительно, на главной диагонали матрицы всегда стоят нули (A[i][i] = 0), так как в простом графе отсутствуют петли (ребра из вершины в саму себя).

Алгоритм

1. Считать число вершин N.
2. Считать матрицу смежности и параллельно подсчитать общее количество единиц.
3. Разделить полученное количество единиц на 2 — это и будет число ребер.
4. Вывести результат.

Пошаговое объяснение на примере

Для входных данных из условия:
```
0 1 1
1 0 1
1 1 0
```
В матрице содержится 6 единиц. Каждое ребро графа представлено парой симметричных единиц, поэтому:
`6 / 2 = 3 ребра`

Это корректно: граф с тремя вершинами, в котором каждая пара соединена ребром, называется треугольником и содержит ровно 3 ребра.
```
Визуализация

    (1)
   /   \
  /     \
(2)-----(3)

```
Матрица смежности:
· Ребро (1,2): A[1][2] = A[2][1] = 1
· Ребро (1,3): A[1][3] = A[3][1] = 1
· Ребро (2,3): A[2][3] = A[3][2] = 1

Итого: 3 ребра, 6 единиц в матрице.

# Показатели эффективности алгоритма

1. Временная сложность

Итоговая оценка: O(N²)

Обоснование:

Основная работа алгоритма — двойной проход по матрице смежности:

|Этап| Сложность| Пояснение|
|----|----------|----------|
Чтение входа| O(N²)| Необходимо прочитать N × N чисел
Подсчет единиц| O(N²)| Проверка каждого элемента матрицы
Деление и вывод| O(1)| Константная операция
Итого| O(N²)| Доминирует квадратичный проход

Нижняя граница: Ω(N²)

Любой корректный алгоритм обязан прочитать все N² элементов матрицы смежности — иначе он не сможет определить наличие ребра в непрочитанной ячейке. Следовательно, временная сложность нашего решения асимптотически оптимальна.

Практическая оценка при N = 100:

· Максимальное число операций: 100 × 100 = 10 000
· Современный процессор: ~10⁸–10⁹ простых операций в секунду
· Ожидаемое время работы: доли миллисекунды
· Лимит: 2 секунды — запас более чем 1000-кратный

2. Пространственная сложность

Итоговая оценка: O(N²)

Обоснование:

Компонент Размер Пояснение
Матрица смежности N × N × 4 байт Хранение всех элементов
Служебные переменные O(1) n, счетчик, индексы
Итого O(N²) Доминирует матрица

Практическая оценка при N = 100:

· Размер матрицы: 105 × 105 × 4 байт ≈ 44 КБ
· Лимит: 256 МБ
· Использование памяти: ~0.017% от доступной

Замечание: Память можно сократить до O(1), не сохраняя матрицу, а подсчитывая единицы «на лету» при чтении. Однако для неориентированного графа без сохранения матрицы придется полагаться на симметричность входа — это работает, но менее наглядно.

3. Класс сложности

· Задача принадлежит классу P (полиномиально разрешимые задачи).
· По структуре — это задача линейного просмотра относительно размера входа (N²).
· Не требует сортировки, рекурсии, динамического программирования или сложных структур данных.

4. Сводная таблица характеристик

## Тестирование и крайние случаи

Проверочные примеры

|Случай| Вход| Ожидаемый| выход| Пояснение|
|------|-----|----------|------|----------|
Пример из условия| N=3, треугольник| 3| Полный граф K₃
N = 1| 1 0| 0| Одна вершина, нет ребер
Пустой граф| N=4, все нули| 0 Нет ни одного ребра
Полный граф| N=4, K₄| 6| N(N−1)/2 = 6
Одно ребро| N=3 с одним ребром| 1| Минимальный ненулевой случай

Проверка формулой

Для полного графа на N вершинах количество ребер:
```
E = N × (N − 1) / 2
При N = 100: E = 100 × 99 / 2 = 4950 ребер. Максимальное возможное значение в задаче — укладывается в int с огромным запасом.
```

## Справочная информация

· Матрица смежности — квадратная матрица A размера N × N, где A[i][j] = 1, если между вершинами i и j есть ребро, и 0 в противном случае.
· Простой граф — граф без петель (ребер из вершины в саму себя) и без кратных ребер.
· Неориентированный граф — граф, в котором ребра не имеют направления, то есть связь между вершинами i и j симметрична.
· Полный граф Kₙ — граф, в котором каждая пара вершин соединена ребром; содержит N(N−1)/2 ребер.

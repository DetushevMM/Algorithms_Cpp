# Реализация класса Stack на C++

## 1. Описание задачи

Необходимо реализовать класс Stack — стек целых чисел, работающий по принципу LIFO (Last In, First Out): последний добавленный элемент извлекается первым.

Класс должен поддерживать следующие операции:

| Метод | Назначение |
|---|---|
| Push(element) | Добавить элемент на вершину стека |
| Pop() | Удалить элемент с вершины стека |
| Top() | Получить значение элемента на вершине без удаления |
| IsEmpty() | Проверить, пуст ли стек |

В качестве внутреннего хранилища используется динамический массив, размер которого автоматически увеличивается при заполнении.

---

## 2. Формат входных данных

В первой строке вводится число N — количество запросов, которые необходимо обработать.

Следующие N строк содержат команды:
- push — на следующей строке вводится целое число, которое добавляется в стек;
- pop — удалить верхний элемент;
- top — вывести значение верхнего элемента;
- is_empty — вывести:
  - Пуст, если стек пуст;
  - Не пуст, если стек содержит хотя бы один элемент.

4. Принцип работы стека

Стек работает по принципу LIFO:
```
Добавление:

    ↓ вершина
  ┌───┐
  │ 3 │ ← последний добавленный
  ├───┤
  │ 2 │
  ├───┤
  │ 1 │
  └───┘
```
Удаление происходит только с вершины.

Если выполнить:
```
push(1)
push(2)
push(3)
```
стек будет выглядеть так:
```
[1, 2, 3]
       ↑
     top
```
После pop() элемент 3 удаляется, и вершиной становится 2.

5. Внутреннее устройство класса

Класс Stack содержит три основных поля:
```
int* data_;
int capacity_;
int top_;
```
- data_ - Указатель на динамический массив, в котором хранятся элементы стека.
- capacity_ - Текущая вместимость массива — максимальное количество элементов, которое можно хранить без его расширения. При создании объекта начальная вместимость равна 10.
- top_ - Количество элементов в стеке и одновременно индекс первой свободной ячейки массива.

Например:
```
data_ = [10, 20, 30, _, _, ...]
         0   1   2   3

top_ = 3
```
В стеке находятся три элемента.

Следующий элемент будет записан в: `data_[top_]`, то есть в data_[3].

Текущая вершина стека находится по адресу: `data_[top_ - 1]`

6. Алгоритмы основных операций

6.1. Push(element) — добавление элемента

Метод добавляет элемент на вершину стека.

Алгоритм:
1. Проверить, заполнен ли массив: `top_ == capacity_`
2. Если массив заполнен — вызвать Resize().
3. Записать новый элемент в data_[top_].
4. Увеличить top_ на единицу.

Фрагмент реализации:
```
void Push(int elem) {
  if (top_ == capacity_) {
    Resize();
  }
  data_[top_] = elem;
  top_++;
}
```
Пример

До операции:
```
data_ = [1, 2, _, _, ...]
top_ = 2
```
Выполняется: Push(3);

После операции:
```
data_ = [1, 2, 3, _, ...]
top_ = 3
```
Вершиной становится элемент 3.

Сложность
- обычный Push: O(1)
- при необходимости расширения: O(n)
- амортизированная сложность: O(1)

---

6.2. Pop() — удаление элемента

Метод удаляет элемент с вершины стека.

Алгоритм:

1. Проверить, пуст ли стек.
2. Если стек не пуст, уменьшить top_ на единицу.
```
void Pop() {
  if (!IsEmpty()) {
    top_--;
  }
}
```
Физически элемент из массива не удаляется.

Например:

До:
```
data_ = [1, 2, 3, ...]
top_ = 3
```
После Pop():
```
data_ = [1, 2, 3, ...]
top_ = 2
```
Теперь элемент 3 не считается частью стека.

При следующем Push() соответствующая ячейка будет перезаписана.

Сложность O(1)

---

6.3. Top() — получение вершины

Метод возвращает значение верхнего элемента, не удаляя его.
```
int Top() {
  return data_[top_ - 1];
}
```
Если:
```
data_ = [10, 20, 30, ...]
top_ = 3
```
то: Top() вернёт: 30

Сложность O(1)

---

6.4. IsEmpty() — проверка пустоты

Стек считается пустым, если количество элементов равно нулю:
```
bool IsEmpty() {
  return top_ == 0;
}
```
Если: top_ == 0, результат: true

Если: top_ > 0, результат: false

Сложность O(1)

---

7. Алгоритм Resize() — расширение массива

Динамический массив имеет ограниченную вместимость.

Если: `top_ == capacity_`, все его ячейки заняты, поэтому перед добавлением нового элемента необходимо увеличить массив. Используется стратегия удвоения размера.

Например:
```
capacity = 10
        ↓
capacity = 20
        ↓
capacity = 40
        ↓
capacity = 80
```
Алгоритм:

1. Вычислить новую вместимость: `int new_capacity = capacity_ * 2;`
2. Выделить новый массив: `int* new_data = new int[new_capacity];`
3. Скопировать в него все существующие элементы.
4. Освободить старый массив: `delete[] data_;`
5. Переназначить указатель на новый массив.
6. Обновить значение capacity_.

Реализация:
```
void Resize() {
  int new_capacity = capacity_ * 2;
  int* new_data = new int[new_capacity];

  for (int i = 0; i < top_; ++i) {
    new_data[i] = data_[i];
  }

  delete[] data_;

  data_ = new_data;
  capacity_ = new_capacity;
}
```
Почему размер увеличивается в два раза?

Если каждый раз увеличивать массив только на одну ячейку: `10 → 11 → 12 → 13 → ...`

при большом количестве добавлений потребуется многократно копировать уже существующие элементы. Суммарная сложность большого количества операций Push может стать O(N²).

При удвоении: `10 → 20 → 40 → 80 → ...`

расширение происходит значительно реже. Поэтому амортизированная сложность Push остаётся: O(1)

Само отдельное расширение при этом имеет сложность O(n), поскольку необходимо скопировать существующие элементы.

9. Управление памятью

Массив создаётся динамически в конструкторе:
```
Stack() : capacity_(10), top_(0) {
  data_ = new int[capacity_];
}
```
Поэтому после завершения работы объекта необходимо освободить выделенную память.

Для этого используется деструктор:
```
~Stack() {
  delete[] data_;
}
```
Таким образом:
```
Конструктор
    ↓
new int[capacity_]
    ↓
работа стека
    ↓
деструктор
    ↓
delete[] data_
```
Это предотвращает утечку динамической памяти.

10. Обработка запросов в main()

Основная программа:
1. Считывает количество запросов N.
2. Создаёт объект Stack.
3. Последовательно считывает команды.
4. В зависимости от команды вызывает соответствующий метод.

Соответствие команд методам:

Команда Действие
```
push stack.Push(value)
pop stack.Pop()
top stack.Top()
is_empty stack.IsEmpty()
```
Для push дополнительно считывается целое число.

При is_empty результат преобразуется в требуемый текст:
```
true  → Пуст
false → Не пуст
```

11. Сложность алгоритмов

|Операция| Временная сложность |Дополнительная память|
|--------|---------------------|---------------------|
Push()| O(1)| амортизированно O(n) при расширении
Pop()| O(1)| O(1)
Top()| O(1)| O(1)
IsEmpty()| O(1)| O(1)
Resize()| O(n)| O(n) временно
Обработка| N запросов O(N)| амортизированно O(N)


O(n) в таблице для памяти означает общий объём памяти, необходимый для хранения элементов стека. При расширении временно существуют старый и новый массивы, поэтому в момент перераспределения памяти может использоваться дополнительная память.

---

12. Итог

Реализованный класс Stack представляет собой классическую структуру данных LIFO, основанную на динамическом массиве.

Основные особенности реализации:
- элементы добавляются и удаляются только с вершины;
- top_ одновременно хранит количество элементов и индекс первой свободной ячейки;
вместимость массива автоматически увеличивается при заполнении;
- размер массива при расширении удваивается;
- удаление элемента выполняется изменением границы top_, без физического удаления значения из памяти;
- память динамического массива освобождается в деструкторе;
- основные операции имеют сложность O(1);

Push() имеет амортизированную сложность O(1) благодаря удвоению вместимости.

Таким образом, реализация демонстрирует базовые принципы работы стека, динамического массива, управления динамической памятью и амортизированной оценки сложности алгоритмов.

# QuickSort — Хоар

## Описание задачи

- Необходимо реализовать сортировку QuickSort (быстрая сортировка) с разбиением методом Хоара.
- Массив должен быть отсортирован по невозрастанию — от большего значения к меньшему.
- Для разбиения используется опорный элемент, выбранный из середины текущего подмассива.

---

Формат ввода
1. В первой строке вводится "N" — количество чисел.
2. В следующих "N" строках находятся числа.

Пример:
```
10
66
-92
-90
24
-62
53
-11
11
-25
-28
```
---

Формат вывода

Вывести "N" отсортированных чисел, каждое с новой строки.

Для приведённого примера:
```
66
53
24
11
-11
-25
-28
-62
-90
-92
```
---

## Основная идея

QuickSort использует принцип «разделяй и властвуй»:
1. Выбирается опорный элемент "pivot".
2. Массив разделяется на две части методом Хоара.
3. В левой части остаются элементы, которые должны находиться раньше опорного.
4. В правой части — элементы, которые должны находиться позже.
5. Обе части рекурсивно сортируются.

Для сортировки по невозрастанию:
```
элементы > pivot → слева
элементы < pivot → справа
```
Равные элементы могут оказаться с любой стороны.

---

**Функция "Swap"**
```
void Swap(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}
```
Функция меняет местами два элемента массива через временную переменную.

---

**Функция "Partition"**

"Partition" выполняет основное разбиение массива методом Хоара.

Опорный элемент выбирается из середины текущего диапазона:
```
int pivot = arr[low + (high - low) / 2];
```
Такой способ вычисления индекса также предотвращает потенциальное переполнение при сложении "low" и "high".

Для поиска элементов используются два указателя:
```
int i = low - 1;
int j = high + 1;
```
- Указатель "i" движется слева направо, пока элементы больше "pivot".
- Указатель "j" движется справа налево, пока элементы меньше "pivot".

Когда оба указателя останавливаются на элементах, нарушающих требуемый порядок, они меняются местами:
```
Swap(arr[i], arr[j]);
```
Разбиение завершается, когда указатели пересекаются:
```
if (i >= j) {
    return j;
}
```
Возвращаемое значение "j" определяет границу двух получившихся частей.

---

**Функция "QuickSort"**

После разбиения выполняется рекурсивная сортировка двух частей:
```
QuickSort(arr, size, low, pi);
QuickSort(arr, size, pi + 1, high);
```
Левая часть имеет диапазон: `[low, pi]`

Правая часть: `[pi + 1, high]`

Рекурсия продолжается, пока диапазон содержит более одного элемента.

Дополнительная проверка:
```
if (pi < low || pi >= high) {
    return;
}
```
защищает от некорректного результата разбиения.

---

## Пример работы

Исходный массив: [66, -92, -90, 24, -62, 53, -11, 11, -25, -28]

При первом вызове:
```
low = 0
high = 9
```
опорным элементом становится: `pivot = -62`

Метод Хоара переставляет элементы так, чтобы большие значения оказались слева, а меньшие — справа.

После первого разбиения: [66, 53, 24, 11, -11, -25, -28, -62, -90, -92]

Возвращается граница: `j = 6`

После этого алгоритм рекурсивно обрабатывает две части:
```
[66, 53, 24, 11, -11, -25, -28]
[-62, -90, -92]
```
Последовательные разбиения продолжаются до тех пор, пока весь массив не будет отсортирован.

Итог: [66, 53, 24, 11, -11, -25, -28, -62, -90, -92]

## Функция "main"

Сначала считывается количество элементов:
```
int n = 0;

if (!(std::cin >> n) || n < 0) {
    return 1;
}
```
Для хранения массива используется умный указатель: `auto arr = std::make_unique<int[]>(n);`

Затем считываются все элементы массива.

Сортировка запускается: `QuickSort(arr.get(), n, 0, n - 1);`

После завершения сортировки элементы выводятся по одному.

Использование "std::unique_ptr" позволяет автоматически освободить выделенную память после завершения работы с массивом.

# Сложность

|Случай| Время| Дополнительная память|
|------|------|----------------------|
Лучший| O(N log N)| O(log N)
Средний| O(N log N)| O(log N)
Худший| O(N²)| O(N)

В среднем QuickSort выполняет сортировку за O(N log N).

Худший случай возникает, когда разбиение постоянно получается сильно несбалансированным, например опорный элемент оказывается минимальным или максимальным.
Выбор среднего элемента в качестве "pivot" помогает уменьшить вероятность такого разбиения.

---

Особенности метода Хоара
- используются два указателя "i" и "j";
- разбиение выполняется относительно "pivot";
- опорный элемент не обязательно занимает своё окончательное место;
- возвращаемое значение определяет границу между двумя частями;
- равные элементы могут попасть в любую часть;
- алгоритм не является стабильным;
- сортировка выполняется по невозрастанию;
- для массива используется "std::unique_ptr".

---

# Итог

В программе реализована быстрая сортировка QuickSort с разбиением методом Хоара.

Основные особенности:
- сортировка по невозрастанию;
- выбор среднего элемента в качестве "pivot";
- разбиение двумя указателями;
- рекурсивная обработка подмассивов;
- использование "std::unique_ptr" для управления памятью;
- средняя временная сложность — O(N log N);
- худшая временная сложность — O(N²).

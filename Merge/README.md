# Слияние массивов Merge

1. Описание задачи

Необходимо реализовать слияние двух отсортированных по неубыванию массивов.

Даны два массива:
- первый содержит "N" элементов;
- второй содержит "M" элементов.

Оба массива уже отсортированы. Требуется получить новый массив длины "N + M", содержащий все элементы обоих исходных массивов в отсортированном порядке.

Требование к алгоритму

Слияние необходимо выполнить за: O(N + M)

При этом необходимо использовать функцию-компаратор для определения порядка элементов.

---

2. Формат ввода

Вводятся:

1. Число "N" — количество элементов первого массива.
2. "N" отсортированных чисел первого массива.
3. Число "M" — количество элементов второго массива.
4. "M" отсортированных чисел второго массива.

Каждое число может находиться на отдельной строке.

---

3. Формат вывода

Выводится результат слияния двух массивов. В результате должно находиться ровно "N + M" элементов, каждый элемент выводится на новой строке.

---

4. Основная идея алгоритма

Так как оба исходных массива уже отсортированы, выполнять повторную сортировку всех элементов не требуется. Вместо этого используется классический алгоритм слияния двух отсортированных массивов.

Мы одновременно просматриваем оба массива и сравниваем текущие элементы:
```
arr1[i]
arr2[j]
```
- Меньший элемент добавляется в результирующий массив.
- После добавления элемента соответствующий указатель перемещается на следующую позицию.
- Таким образом, каждый элемент обоих массивов обрабатывается только один раз.

---

5. Функция-компаратор

В программе используется функция:
```
bool ComparatorInt(int x, int y) {
    return x < y;
}
```
Она определяет порядок элементов. Функция возвращает "true", если первый аргумент должен находиться перед вторым.

Для сортировки по возрастанию используется: x < y

Компаратор передаётся в функцию слияния:
```
int* MergeArrays(
    const int* arr1,
    int n,
    const int* arr2,
    int m,
    bool (*comp)(int, int)
)
```
Здесь: `bool (*comp)(int, int)` — указатель на функцию, которая принимает два "int" и возвращает "bool".

Это позволяет отделить сам алгоритм слияния от правила сравнения элементов.

---

6. Работа функции "MergeArrays"

Функция получает:

|Параметр| Назначение|
|--------|-----------|
"arr1"| указатель на первый массив
"n"| количество элементов первого массива
"arr2"| указатель на второй массив
"m"| количество элементов второго массива
"comp"| функция-компаратор

Функция создаёт новый массив: `int* result = new int[n + m];`

Размер результата заранее известен и равен сумме размеров исходных массивов.

---

7. Указатели "i", "j" и "k"

В алгоритме используются три индекса:
```
int i = 0;
int j = 0;
int k = 0;
```
Их назначение:
- "i" — текущая позиция в первом массиве;
- "j" — текущая позиция во втором массиве;
- "k" — текущая позиция в результирующем массиве.

Например:
```
arr1: [-84, -43, -25]
        ↑
        i

arr2: [-89, -83, -79]
        ↑
        j

result:
         ↑
         k
```
---

8. Основной цикл слияния

Основная часть алгоритма:
```
while (i < n && j < m) {
    if (comp(arr1[i], arr2[j])) {
        result[k++] = arr1[i++];
    } else {
        result[k++] = arr2[j++];
    }
}
```
Цикл работает, пока в обоих массивах остаются необработанные элементы.

На каждой итерации:
1. Берутся текущие элементы двух массивов.
2. Они сравниваются с помощью "comp".
3. Элемент, который должен идти первым, записывается в "result".
4. Индекс соответствующего массива увеличивается.
5. Индекс "k" также увеличивается.

---

9. Что происходит при равных элементах

Компаратор реализован следующим образом: `return x < y;`

Поэтому если: `arr1[i] == arr2[j]`, то: `comp(arr1[i], arr2[j])` вернёт "false".

В результате будет выбран элемент из второго массива: `result[k++] = arr2[j++];`
```
Например:
arr1 = [-7]
arr2 = [-7]
```
Сначала в результат попадёт элемент второго массива, затем элемент первого. При этом итоговая последовательность всё равно останется отсортированной.

---

10. Добавление оставшихся элементов

Основной цикл заканчивается, когда один из массивов полностью обработан.

Например:
```
arr1: [-84, -43, -25]  → закончился
arr2: [-83, -79]       → остались элементы

Оставшиеся элементы первого массива добавляются следующим циклом:

while (i < n) {
    result[k++] = arr1[i++];
}

Оставшиеся элементы второго массива:

while (j < m) {
    result[k++] = arr2[j++];
}
```
Поскольку исходные массивы уже отсортированы, оставшаяся часть каждого массива также находится в правильном порядке. Поэтому дополнительная сортировка не требуется.

---

11. Пошаговый пример

Рассмотрим:
```
arr1 = [-84, -43, -25]
arr2 = [-89, -83, -79]
```
Шаг 1

Сравниваем: -84 и -89 -> "-89" меньше, поэтому выбираем его: `result = [-89]`

---

Шаг 2

Сравниваем: -84 и -83 -> Выбираем "-84": `result = [-89, -84]`

---

Шаг 3

Сравниваем: -43 и -83 -> Выбираем "-83": `result = [-89, -84, -83]`

---

Шаг 4

Сравниваем: -43 и -79 -> Выбираем "-79": `result = [-89, -84, -83, -79]`

---

Шаг 5

Сравниваем: -43 и -79 -> После перемещения указателя второго массива он закончился.

Оставшийся элемент первого массива: -43, -25 добавляется в результат.

Итог: [-89, -84, -83, -79, -43, -25]

---

12. Корректность алгоритма
- Алгоритм корректен благодаря тому, что оба входных массива уже отсортированы.
- На каждом шаге среди двух текущих элементов выбирается тот, который должен находиться первым в результирующем массиве.
- Все элементы, находящиеся после выбранного элемента в соответствующем массиве, не могут быть меньше него, поскольку массив отсортирован.
- Следовательно, выбранный элемент можно безопасно помещать в результат.

После обработки одного из массивов все элементы второго массива уже находятся в правильном порядке и могут быть просто скопированы в конец результата.

Таким образом:

- каждый элемент первого массива добавляется ровно один раз;
- каждый элемент второго массива добавляется ровно один раз;
- ни один элемент не теряется;
- порядок элементов сохраняется.

---

13. Сложность алгоритма

Временная сложность: O(N + M)

Каждый элемент двух массивов обрабатывается не более одного раза.

Если:
```
N = 10
M = 8
```
то всего необходимо обработать: N + M = 18 элементов.

Алгоритм не выполняет дополнительную сортировку.

---

Пространственная сложность: O(N + M)

Для результата выделяется новый массив: `int* result = new int[n + m];`. Его размер равен "N + M".

Дополнительная память, используемая непосредственно для индексов и указателей, составляет "O(1)".

Таким образом:

- память под результат — "O(N + M)";
- дополнительная служебная память — "O(1)".

Если учитывать память, необходимую для хранения результата, общая пространственная сложность составляет O(N + M).

---

14. Управление памятью

В программе используются динамические массивы:
```
int* arr1 = new int[n];
int* arr2 = new int[m];
int* merged = MergeArrays(arr1, n, arr2, m, ComparatorInt);
```
После завершения работы с массивами выделенная память освобождается:
```
delete[] arr1;
delete[] arr2;
delete[] merged;
```
Это необходимо, поскольку память была выделена оператором "new[]".

В реализации не используются контейнеры STL, например "std::vector". Управление памятью выполняется вручную.

---

15. Особенности реализации

1. Использование "const"

Параметры исходных массивов объявлены как:
```
const int* arr1
const int* arr2
```
Это гарантирует, что функция "MergeArrays" не изменит исходные массивы.

---

2. Указатель на функцию

Компаратор передаётся следующим образом: `bool (*comp)(int, int)`

Это позволяет использовать один и тот же алгоритм с разными правилами сравнения. Например, для обратного порядка можно определить другой компаратор:
```
bool ComparatorDescending(int x, int y) {
    return x > y;
}
```
При этом сам алгоритм "MergeArrays" изменять не требуется.

Важно, чтобы входные массивы соответствовали тому же порядку сортировки, который задаёт компаратор.

---

3. Отсутствие STL-контейнеров. В реализации используются:
- обычные массивы;
- указатели;
- динамическое выделение памяти;
- указатель на функцию.

Это позволяет непосредственно продемонстрировать механизм работы алгоритма слияния и ручное управление памятью в C++.

17. Итог

Задача демонстрирует классический алгоритм Merge — слияние двух отсортированных массивов.

Ключевая идея:
```
два отсортированных массива
          ↓
  сравнение текущих элементов
          ↓
выбор меньшего элемента
          ↓
добавление в результат
          ↓
повторение
```
Алгоритм позволяет объединить два отсортированных массива за O(N + M) без дополнительной сортировки.

В реализации дополнительно продемонстрированы:

- работа с динамическими массивами;
- указатели;
- "const"-указатели;
- указатели на функции;
- функция-компаратор;
- ручное управление динамической памятью;
- алгоритм слияния, являющийся одной из ключевых операций сортировки слиянием.

# Правильные скобочные последовательности

## Задача

Определить, является ли входная строка правильной скобочной последовательностью (ПСП).

Используются три типа скобок:

- "()"
- "[]"
- "{}"

Буквы и цифры не влияют на результат и должны игнорироваться.

Результат:

- "CORRECT" — последовательность корректна;
- "INCORRECT" — последовательность содержит ошибку.

Формат ввода: Одна строка, содержащая скобки, цифры и английские буквы.

Формат вывода: `CORRECT` или `INCORRECT`

## Алгоритм

Для проверки используется стек LIFO: последняя открытая скобка должна закрываться первой.

Для каждого символа:

1. Открывающая скобка "(", "[" или "{" помещается в стек.
2. Закрывающая скобка ")", "]" или "}":
   - если стек пуст — последовательность некорректна;
   - извлекается последняя открывающая скобка;
   - проверяется соответствие пары.
3. Буквы и цифры пропускаются.

После обработки всей строки стек должен быть пустым.

Условия ошибки

Последовательность является "INCORRECT", если:
- встретилась закрывающая скобка при пустом стеке;
- тип закрывающей скобки не соответствует последней открывающей;
- после завершения строки в стеке остались открывающие скобки.

## Пример

Для строки:
```
([{}])

обработка происходит следующим образом:

(  → push '('
[  → push '['
{  → push '{'
}  → pop '{' ✓
]  → pop '[' ✓
)  → pop '(' ✓

Стек пуст → "CORRECT".
```
Для:
```
([)]

после "([" верхняя скобка — "[". Встречается ")", поэтому пара не совпадает:

[ + ) → ошибка
```
Результат: `INCORRECT`

## Реализация стека

STL не используется. Стек реализован вручную на основе динамического массива:
```
char* data_;
int capacity_;
int top_;
```
- "Push()" — добавляет элемент;
- "Pop()" — извлекает верхний элемент;
- "Peek()" — возвращает верхний элемент без удаления;
- "IsEmpty()" — проверяет пустоту стека.

В данной реализации для хранения строки и стека используется ограничение в "1000" символов.

Основные функции
- bool IsOpen(char bracket);
- Проверяет, является ли символ открывающей скобкой.
- bool IsClose(char bracket);
- Проверяет, является ли символ закрывающей скобкой.
- bool IsMatching(char open, char close);

Проверяет соответствие открывающей и закрывающей скобок.

## Тесты

|Ввод| Вывод|
|----|------|
"(()())()"| "CORRECT"
"()[]{}(a)(())"| "CORRECT"
"(()"| "INCORRECT"
"(()(())))"| "INCORRECT"
"([)]"| "INCORRECT"
"()"| "CORRECT"
")("| "INCORRECT"
"abc123"| "CORRECT"

## Сложность

Пусть "n" — длина входной строки.

- Время: "O(n)" — каждый символ обрабатывается один раз.
- Память: "O(n)" — в худшем случае все символы-скобки помещаются в стек.

## Итог

Основная идея решения:
```
строка
  ↓
открывающая скобка → PUSH
  ↓
закрывающая скобка → POP + проверка пары
  ↓
буква/цифра → пропуск
  ↓
конец строки → стек должен быть пуст
```
Стек естественно соответствует правилу ПСП: последняя открытая скобка должна закрыться первой.

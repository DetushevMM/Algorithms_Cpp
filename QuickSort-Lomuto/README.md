# QuickSort — Ломуто

Описание задачи
- Необходимо реализовать сортировку QuickSort (быстрая сортировка) с разбиением методом Ломуто.
- Массив должен быть отсортирован по невозрастанию — от большего значения к меньшему.

---

Формат ввода
1. В первой строке вводится "N" — количество чисел.
2. В следующих "N" строках находятся числа.

Пример:
```
10
66
-92
-90
24
-62
53
-11
11
-25
-28
```
---

Формат вывода
1. Вывести "N" отсортированных чисел, каждое с новой строки.

Для приведённого примера:
```
66
53
24
11
-11
-25
-28
-62
-90
-92
```
---

## Основная идея

QuickSort использует принцип «разделяй и властвуй»:
1. Выбирается опорный элемент "pivot".
2. Массив разделяется на две части методом Ломуто.
3. Элементы, большие "pivot", перемещаются в левую часть.
4. После завершения прохода "pivot" устанавливается между двумя частями.
5. Обе части рекурсивно сортируются.

Для сортировки по невозрастанию используется условие: `arr[j] > pivot`

---

**Функция "Swap"**
```
void Swap(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}
```
Функция меняет местами два элемента массива через временную переменную.

---

**Функция "Partition"**

"Partition" выполняет разбиение текущего подмассива методом Ломуто.

Опорным элементом выбирается последний элемент: `int pivot = arr[high];`

Индекс "i" обозначает границу области элементов, которые больше "pivot": `int i = low - 1;`

Затем индекс "j" последовательно проходит по всем элементам перед "pivot":
```
for (int j = low; j < high; ++j) {
    if (arr[j] > pivot) {
        i++;
        Swap(arr[i], arr[j]);
    }
}
```
Если текущий элемент больше "pivot", он должен находиться слева. Поэтому граница "i" увеличивается, после чего элементы меняются местами.

После завершения цикла опорный элемент перемещается на границу двух частей: `Swap(arr[i + 1], arr[high]);`

Функция возвращает его окончательную позицию: `return i + 1;`

Таким образом, после разбиения:
```
элементы > pivot → слева
pivot             → в середине
элементы ≤ pivot → справа
```
---

**Функция "QuickSort"**

После разбиения функция рекурсивно сортирует две получившиеся части:
```
QuickSort(arr, low, pi - 1);
QuickSort(arr, pi + 1, high);
```
Левая часть: `[low, pi - 1]`

Правая часть: `[pi + 1, high]`

Если "low >= high", подмассив содержит не более одного элемента и считается отсортированным.

---

## Пример работы

Исходный массив: [66, -92, -90, 24, -62, 53, -11, 11, -25, -28]

При первом вызове:
```
low = 0
high = 9
pivot = -28
```
В процессе разбиения все элементы, большие "-28", перемещаются в левую часть.

После завершения "Partition": [66, 24, 53, -11, 11, -25, -28, -62, -90, -92]

Опорный элемент "-28" находится на позиции "6".

Далее алгоритм независимо сортирует:
```
[66, 24, 53, -11, 11, -25]

и

[-62, -90, -92]
```
После последовательных рекурсивных разбиений получается: [66, 53, 24, 11, -11, -25, -28, -62, -90, -92]

---

**Функция "main"**

Сначала считывается количество элементов:
```
int n = 0;

if (!(std::cin >> n) || n < 0) {
    return 1;
}
```
Для хранения массива используется "std::vector": `std::vector<int> arr(n);`

Контейнер автоматически управляет выделением и освобождением памяти.

После чтения всех элементов запускается сортировка:
```
if (n > 1) {
    QuickSort(arr, 0, n - 1);
}
```
Проверка "n > 1" позволяет не выполнять рекурсию для массива из одного элемента или пустого массива.

## Сложность

|Случай| Время| Дополнительная память|
|------|------|----------------------|
Средний| O(N log N)| O(log N)
Худший| O(N²)| O(N)

В среднем QuickSort работает за O(N log N).

Худший случай возникает, когда выбранный "pivot" постоянно оказывается минимальным или максимальным элементом. Например, для уже отсортированного по возрастанию массива последний элемент будет максимальным, поэтому одна из частей после каждого разбиения будет пустой.

В результате рекурсивно обрабатываются массивы размеров: `N, N-1, N-2, ..., 1`, что приводит к сложности O(N²).

---

Особенности метода Ломуто
- "pivot" выбирается на правой границе подмассива;
- используется один основной проход по элементам;
- индекс "i" определяет границу элементов, больших "pivot";
- после прохода "pivot" устанавливается на окончательную позицию;
- полученная позиция "pivot" используется для дальнейшего рекурсивного разбиения;
- равные элементы относятся к правой части;
- алгоритм нестабильный.

---

### Сравнение с методом Хоара

|Метод Ломуто| Метод Хоара|
|------------|------------|
Более простая логика разбиения| Более сложная логика
"pivot" выбирается на границе| "pivot" может выбираться из середины
Используется один проход с индексом "j"| Используются два указателя
После разбиения "pivot" занимает свою позицию| Граница разбиения не обязательно является позицией "pivot"
Может выполнять больше обменов| Обычно требует меньше обменов

# Итог

В программе реализована сортировка QuickSort с разбиением методом Ломуто.

Основные особенности:

- сортировка по невозрастанию;
- "pivot" выбирается как последний элемент;
- используется метод разбиения Ломуто;
- сортировка выполняется рекурсивно;
- для хранения данных используется "std::vector";
- средняя временная сложность — O(N log N);
- худшая временная сложность — O(N²);
- алгоритм является нестабильным.

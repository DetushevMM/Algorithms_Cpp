# Лестница — динамическое программирование

## 1. Описание задачи

Дана лестница из n ступенек, где: `1 ≤ n ≤ 100`

Каждая ступенька имеет целочисленную стоимость: `-10^4 ≤ ai ≤ 10^4`

Необходимо подняться от земли до последней ступеньки.

За один ход можно подняться:
- на 1 ступеньку;
- на 2 ступеньки.

При попадании на ступеньку к общей сумме добавляется число, которым она помечена.

Требуется найти максимальную сумму, которую можно получить, достигнув последней ступеньки.

---

2. Принцип решения

Задача решается методом динамического программирования.

Основная идея: для каждой ступеньки отдельно вычисляется максимальная сумма, которую можно получить, добравшись до неё.

Создаётся массив: int* max_sum;, где: max_sum[i] — максимальная сумма, которую можно получить, достигнув i-й ступеньки.

После вычисления значения для каждой ступеньки оно используется при расчёте следующих.

---

3. Почему достаточно проверить две предыдущие ступеньки

На ступеньку i можно попасть только двумя способами: i-2 → i или i-1 → i

Других вариантов нет, поскольку разрешено делать только шаг на 1 или 2 ступеньки. Поэтому максимальная сумма для ступеньки i определяется так:
```
max_sum[i] =
    max(max_sum[i - 1], max_sum[i - 2]) + stairs[i]
```
В коде:
```
int from_prev = max_sum[i - 1] + stairs[i];
int from_prev2 = max_sum[i - 2] + stairs[i];

max_sum[i] = (from_prev > from_prev2) ? from_prev : from_prev2;
```
---

4. Базовые случаи

4.1. Первая ступенька

Для i = 0 существует только один вариант попасть на неё — сразу с земли.

Поэтому: `max_sum[0] = stairs[0];`

Например:
```
stairs = [-1, 2, 1]
max_sum[0] = -1
```
---

4.2. Вторая ступенька

Для i = 1 есть уже два возможных пути: Вариант 1 — через первую ступеньку
```
земля → 0 → 1
```
Сумма: `max_sum[0] + stairs[1]`

Вариант 2 — сразу с земли
```
земля → 1
```
Сумма: stairs[1]

Выбирается максимальное значение:
```
int from_zero = max_sum[0] + stairs[1];
int from_ground = stairs[1];

max_sum[1] =
    (from_zero > from_ground) ? from_zero : from_ground;
```
Важно учитывать второй вариант, потому что с земли разрешено сразу перепрыгнуть на вторую ступеньку.

---

5. Переход для остальных ступенек
- Для всех i ≥ 2 рассматриваются два варианта.
- Вариант 1 — шаг с предыдущей ступеньки `from_prev = max_sum[i - 1] + stairs[i];`
- Вариант 2 — прыжок через одну ступеньку `from_prev2 = max_sum[i - 2] + stairs[i];`
- Выбирается максимальный вариант:
```
max_sum[i] = (from_prev > from_prev2)
                 ? from_prev
                 : from_prev2;
```
Таким образом, для каждой ступеньки сохраняется только лучший известный путь до неё.

---

6. Пример работы алгоритма

Рассмотрим пример:
```
n = 3
stairs = [-1, 2, 1]
```
Ступенька 0: `max_sum[0] = -1`

Получаем: [-1, ?, ?]

---

Ступенька 1
- Путь через ступеньку 0: -1 + 2 = 1
- Путь непосредственно с земли: 2
- Выбираем: max_sum[1] = max(1, 2) = 2

Состояние: [-1, 2, ?]

---

Ступенька 2
- Путь с предыдущей ступеньки: 2 + 1 = 3
- Путь через одну ступеньку: -1 + 1 = 0
- Выбираем: `max_sum[2] = max(3, 0) = 3`
- Получаем: [-1, 2, 3]

Ответ: 3

Оптимальный путь: земля → 1-я ступенька → 2-я ступенька → 3-я ступенька с суммой: -1 + 2 + 1 = 2

Однако при используемой в условии индексации ступенек и переходов важно интерпретировать массив как значения ступенек 0..n-1: для приведённого алгоритма итоговое значение 3 соответствует выбору: 2 + 1 = 3, то есть прыжку с первой значимой ступеньки на последнюю.

---

7. Работа с отрицательными значениями

В задаче разрешены отрицательные значения: -10000 ≤ ai ≤ 10000

Алгоритм не предполагает, что нужно просто избегать отрицательных ступенек.

Он сравнивает полные суммы путей.

Например: `stairs = [2, -1]`

Для второй ступеньки возможны два пути: земля → 1

Сумма: -1 и: земля → 0 → 1

Сумма: 2 + (-1) = 1

Поэтому: `max_sum[1] = 1`

Алгоритм автоматически выбирает путь с максимальной общей суммой.

9. Общий алгоритм программы

Программа выполняет следующие действия:
1. Считывает количество ступенек n.
2. Выделяет динамический массив stairs для хранения значений ступенек.
3. Считывает значения всех ступенек.
4. Выделяет массив max_sum для результатов динамического программирования.
5. Инициализирует первую ступеньку.
6. Если ступенек больше одной, вычисляет оптимальный результат для второй.
7. Начиная с третьей ступеньки, последовательно вычисляет:
   - сумму при переходе с предыдущей ступеньки;
   - сумму при переходе через одну ступеньку;
   - максимум из двух вариантов.
8. Выводит max_sum[n - 1].
9. Освобождает динамически выделенную память.

---

10. Псевдокод
```
прочитать n

создать массив stairs
прочитать значения stairs

создать массив max_sum

max_sum[0] = stairs[0]

если n > 1:
    через_нулевую = max_sum[0] + stairs[1]
    с_земли = stairs[1]

    max_sum[1] = максимум(через_нулевую, с_земли)

для i от 2 до n - 1:
    через_предыдущую = max_sum[i - 1] + stairs[i]
    через_одну = max_sum[i - 2] + stairs[i]

    max_sum[i] = максимум(
        через_предыдущую,
        через_одну
    )

вывести max_sum[n - 1]
```

11. Почему это динамическое программирование

Задача соответствует классическому подходу динамического программирования, потому что:

1. Задача разбивается на подзадачи

Чтобы определить лучший путь до ступеньки i, достаточно знать лучшие результаты для:
```
i - 1
i - 2
```
2. Подзадачи имеют оптимальную структуру

Если лучший путь до i пришёл с i-1, то часть пути до i-1 также должна быть оптимальной. Иначе существовал бы более выгодный путь до i-1, который дал бы лучший результат и для i.

3. Результаты сохраняются

Вместо повторного вычисления всех возможных путей программа сохраняет результат: `max_sum[i]` и использует его при расчёте следующих ступенек. Это позволяет решить задачу за линейное время.

---

12. Сложность алгоритма

Пусть n — количество ступенек.
- Время: Массив обрабатывается один раз: O(n). Для каждой ступеньки выполняется постоянное количество операций.
- Память: Используются два массива:
```
stairs
max_sum
```
Каждый имеет размер n.

Поэтому дополнительная память: O(n)

Итог:

|Показатель | Сложность|
|-----------|----------|
Время| O(n)
Память| O(n)

---

13. Управление динамической памятью

В программе используются динамические массивы:
```
int* stairs = new int[n];
int* max_sum = new int[n];
```
После завершения вычислений память освобождается:
```
delete[] stairs;
delete[] max_sum;
```
Это необходимо, поскольку память была выделена оператором new[].

---

14. Итог

Задача решается методом динамического программирования.

Ключевая формула:
```
max_sum[i] =
    max(max_sum[i - 1], max_sum[i - 2]) + stairs[i]
```
Для первой и второй ступенек используются отдельные базовые случаи.

Главная идея алгоритма заключается в том, что для достижения очередной ступеньки достаточно рассмотреть только два последних возможных положения:
```
i - 1
i - 2
```
и выбрать тот вариант, который даёт большую накопленную сумму.

Итоговая сложность:
```
Время:  O(n)
Память: O(n)
```
Алгоритм корректно работает как с положительными, так и с отрицательными значениями ступенек и учитывает возможность сразу перейти с земли на вторую ступеньку.

## Binary Search Tree (BST)

**Описание задачи**

Необходимо реализовать несбалансированное бинарное дерево поиска (BST).

Поддерживаются следующие операции:

- "push(elem)" — добавить элемент;
- "pop(elem)" — удалить элемент;
- "find(elem)" — проверить наличие элемента;
- "get_min()" — получить минимальный элемент;
- "get_max()" — получить максимальный элемент.

Элементы могут повторяться.

Свойство BST

Для каждого узла:

- элементы меньше либо равные значению узла находятся в левом поддереве;
- элементы больше значения узла находятся в правом поддереве.

При добавлении дубликаты помещаются в левое поддерево.

---

Формат ввода

В первой строке задаётся количество запросов "N".

Далее идут команды:
```
push 5
pop 3
find 6
get_min
get_max
```
Для "push", "pop" и "find" после команды указывается целое число.

---

Формат вывода

Для "find":

TRUE - если элемент найден, и FALSE - если элемента нет.

Для "get_min" и "get_max" выводится найденное значение.

Если дерево пустое, эти операции ничего не выводят.

---

# Алгоритмы

1. "push(elem)" — добавление

Начиная с корня, сравниваем новый элемент со значением текущего узла:

- если "elem <= current->value", переходим влево;
- если "elem > current->value", переходим вправо.

Когда найден пустой указатель, создаётся новый узел.
```
Node** current = &root_;

while (*current) {
    if (element <= (*current)->value) {
        current = &(*current)->left;
    } else {
        current = &(*current)->right;
    }
}

*current = new Node(element);
```
Использование "Node**" позволяет непосредственно изменить указатель на корень или дочерний узел.

Сложность: "O(h)", где "h" — высота дерева.

---

2. "find(elem)" — поиск

Поиск использует то же свойство BST:

- если значение найдено — возвращается "true";
- если "elem" меньше текущего значения — поиск продолжается слева;
- если больше — справа;
- если достигнут "nullptr", элемента нет.
```
while (current) {
    if (element == current->value) {
        return true;
    }

    current = (element < current->value)
                  ? current->left
                  : current->right;
}

return false;
```
Сложность: "O(h)".

---

3. "get_min()" — минимальный элемент

Минимальное значение BST находится в самом левом узле.

Алгоритм:

1. начать с корня;
2. переходить по "left";
3. остановиться, когда левого ребёнка нет.
```
        8
       / \
      3   12
     / \
    1   5
```
Минимальный элемент — "1".

Метод возвращает "false", если дерево пустое, иначе записывает результат в переданный параметр "out".

Сложность: "O(h)", дополнительная память "O(1)".

---

4. "get_max()" — максимальный элемент
```
Работает аналогично "get_min()", но движение выполняется вправо.

        8
       / \
      3   12
         /  \
        10   15
```
Максимальный элемент — "15".

Сложность: "O(h)", дополнительная память "O(1)".

---

5. "pop(elem)" — удаление

Удаление состоит из двух этапов:

1. поиск удаляемого узла;
2. перестроение его участка дерева.

Возможны три случая. Случай 1 — узел является листом
```
У узла нет детей:

    5
   /
  3

Узел удаляется:

    5
```
---

Случай 2 — один ребёнок. Если у узла только один ребёнок, узел заменяется этим ребёнком:
```
    5
   /
  3
   \
    4

После удаления "3":

    5
   /
  4
```
---

Случай 3 — два ребёнка
```
Например:

      8
     / \
    3   12
       /  \
      10   15
```
При удалении "12" нельзя просто удалить узел, поскольку необходимо сохранить структуру BST.

Используется минимальный элемент правого поддерева — следующий элемент в порядке обхода (in-order successor).

Для "12" это "15":

1. найти минимум в правом поддереве;
2. скопировать его значение в удаляемый узел;
3. удалить найденный узел из правого поддерева.

В коде:
```
Node* min_node = node->right;

while (min_node->left) {
    min_node = min_node->left;
}

node->value = min_node->value;
Remove(node->right, min_node->value);
```
Так сохраняется свойство BST.

Почему используется "Node*&"bool Remove(Node*& node, int element) - Ссылка на указатель позволяет непосредственно изменить указатель родителя или "root_".

Например: `node = node->right;` заменяет удалённый узел его правым ребёнком. Это также позволяет одинаково обрабатывать удаление обычного узла и корня.

Сложность: "O(h)" по времени и "O(h)" дополнительной памяти в худшем случае из-за рекурсии.

---

Дубликаты

При добавлении используется условие:
```
if (element <= (*current)->value)
    current = &(*current)->left;
```
Поэтому одинаковые элементы помещаются в левое поддерево.

При "pop(elem)" удаляется первый найденный узел с таким значением. Остальные дубликаты сохраняются.

---

Освобождение памяти
- Деструктор вызывает: `Destroy(root_);`
- "Destroy()" выполняет пост-обход дерева:
1. удалить левое поддерево;
2. удалить правое поддерево;
3. удалить текущий узел.
```
void Destroy(Node* node) {
    if (node) {
        Destroy(node->left);
        Destroy(node->right);
        delete node;
    }
}
```
Так освобождаются все динамически созданные узлы.

Сложность: "O(N)" по времени и "O(h)" памяти стека.

# Оценка сложности

"h" — высота дерева, "N" — количество узлов.

|Операция| Средний случай| Худший случай|
|--------|---------------|--------------|
"push"| "O(log N)"| "O(N)"
"find"| "O(log N)"| "O(N)"
"get_min"| "O(log N)"| "O(N)"
"get_max"| "O(log N)"| "O(N)"
"pop"| "O(log N)"| "O(N)"

Дополнительная память:

- итеративные операции — "O(1)";
- "pop" — до "O(h)" из-за рекурсии;
- уничтожение дерева — "O(h)" памяти стека.

Худший случай возникает, если элементы добавляются в уже отсортированном порядке. Тогда дерево превращается в цепочку:
```
1
 \
  2
   \
    3
     \
      4
       \
        5
```
Его высота становится "O(N)", поэтому операции выполняются за "O(N)".

В отличие от AVL-дерева, данное BST не выполняет балансировку.

---

# Основные особенности реализации

- дерево реализовано вручную без STL;
- каждый элемент хранится в динамическом узле "Node";
- дубликаты помещаются в левое поддерево;
- удаление учитывает все три варианта количества детей;
- минимум ищется по левым ссылкам, максимум — по правым;
- деструктор освобождает все созданные узлы;
- для изменения указателей используется "Node**" при добавлении и "Node*&" при удалении.

# Задача о клептомане

1. Задача

Есть рюкзак с ограничением по максимальному весу и "N" предметов с известными весами.

Необходимо определить максимальное количество предметов, которые можно взять так, чтобы их суммарный вес не превышал грузоподъёмность рюкзака.

Например:

Максимальный вес: 100

Предметы: 31 35 46 49 54 79 82 93 99 99

Можно взять: 31 + 35 = 66

Третий предмет уже не помещается: 66 + 46 = 112 > 100

Ответ: 2

---

2. Основная идея решения

Поскольку все предметы имеют одинаковую ценность — каждый предмет даёт ровно "+1" к ответу, для максимизации количества выгодно сначала брать самые лёгкие предметы.

Поэтому алгоритм:

1. Считать максимальную грузоподъёмность.
2. Считать веса предметов.
3. Отсортировать веса по возрастанию.
4. Последовательно брать самые лёгкие предметы.
5. Остановиться, когда следующий предмет уже не помещается.
6. Вывести количество взятых предметов.

После сортировки мы всегда рассматриваем предметы от самых лёгких к самым тяжёлым:

[31, 35, 46, 49, 54, 79, 82, 93, 99, 99]

---

3. Почему достаточно брать самые лёгкие предметы

Предположим, существует решение с "k" предметами.

Если в нём находится тяжёлый предмет, а какой-то более лёгкий предмет не выбран, можно заменить тяжёлый предмет на лёгкий.

Количество предметов останется тем же: 1 предмет → 1 предмет, но общий вес не увеличится.

Значит, для максимального количества предметов оптимально рассматривать предметы в порядке увеличения веса. Это и позволяет использовать жадный выбор.

---

4. Сортировка предметов

В программе используется пузырьковая сортировка:
```
void SortArray(DynamicArray& arr) {
  int n = arr.GetSize();

  for (int i = 0; i < n - 1; ++i) {
    for (int j = 0; j < n - i - 1; ++j) {
      if (arr[j] > arr[j + 1]) {
        int temp = arr[j];
        arr[j] = arr[j + 1];
        arr[j + 1] = temp;
      }
    }
  }
}
```
На каждом проходе сравниваются соседние элементы.

Если левый элемент больше правого, они меняются местами: [35, 31] и становится: [31, 35].

После сортировки веса расположены от меньшего к большему.

---

5. Выбор предметов

После сортировки используется простой проход:
```
int count = 0;
int current = 0;

for (int i = 0; i < weights.GetSize(); ++i) {
  if (current + weights[i] <= max_weight) {
    current += weights[i];
    count++;
  } else {
    break;
  }
}
```
Здесь:

- "current" — текущий суммарный вес рюкзака;
- "count" — количество выбранных предметов;
- "weights[i]" — очередной предмет.

Если предмет помещается: `current + weights[i] <= max_weight`, то:
```
current += weights[i]
count++
```
Если не помещается: `current + weights[i] > max_weight` -> выполняется: break;

Почему можно сразу остановиться?

Массив отсортирован по возрастанию. Если текущий предмет уже не помещается, то все следующие предметы будут не легче текущего. Следовательно, ни один из них также не сможет поместиться.

7. Динамический массив

В программе не используется "std::vector". Вместо него реализован собственный динамический массив: class DynamicArray

Он хранит:
```
int* data_;
int size_;
int capacity_;
```
где:

- "data_" — указатель на выделенную память;
- "size_" — количество реально сохранённых элементов;
- "capacity_" — размер выделенной области памяти.

*"PushBack"*

При добавлении нового элемента проверяется наличие свободного места: `if (size_ >= capacity_)`

Если места нет, создаётся новый массив в два раза больше: 
`int new_capacity = (capacity_ == 0) ? 1 : capacity_ * 2;`

Старые элементы копируются:
```
старый массив:
[31, 35, 46]
capacity = 4

       ↓ заполнение

новый массив:
[31, 35, 46, ...]
capacity = 8
```
После этого старый массив удаляется.

Такой подход позволяет добавлять элементы без выделения новой памяти при каждом "PushBack".

Амортизированная сложность добавления — "O(1)".

---

8. Важное замечание о динамическом программировании

В условии указано:

«Используйте принципы одномерного динамического программирования.» Однако данная реализация не использует динамическое программирование.

Она использует: *сортировка + жадный алгоритм*

Для конкретной задачи это работает, потому что все предметы имеют одинаковую ценность: нам важно только их количество.

Классический вариант одномерного ДП можно было бы сформулировать через состояние:
```
dp[w] = максимальное количество предметов,
       которое можно получить при ограничении веса w
```
Но для данной задачи сортировка и выбор самых лёгких предметов дают более простое решение.

---

9. Почему это не обычная задача о рюкзаке

Классическая задача о рюкзаке обычно содержит для каждого предмета: вес + ценность

Например:
```
Предмет    Вес    Ценность
A          10     100
B          20     200
C          30     1000
```
Тогда самый лёгкий предмет не обязательно является лучшим выбором.

В данной задаче ценность каждого предмета одинаковая: любой предмет → +1 к ответу

Поэтому для максимизации количества достаточно минимизировать используемый вес.

---

Пример:
```
100
10
31
35
46
49
54
79
82
93
99
99
```
---

Вывести одно число: максимальное количество предметов

Для приведённого примера: 2

10. Сложность

|Этап| Сложность|
|----|----------|
Чтение предметов| "O(N)"
Пузырьковая сортировка| "O(N²)"
Выбор предметов| "O(N)"
Общая сложность| "O(N²)"
Память для весов| "O(N)"

Основная часть времени тратится на пузырьковую сортировку.

Если заменить её на сортировку "O(N log N)", например быструю сортировку, общая сложность алгоритма также улучшится до "O(N log N)".

## Главное

Цель: максимальное количество предметов.

Поскольку каждый предмет одинаково ценен,
сначала выбираем самые лёгкие.

Сортируем веса:
от меньшего к большему.

Берём предметы, пока следующий не превышает оставшуюся грузоподъёмность.

# Кратчайшие расстояния от вершины S в неориентированном невзвешенном графе

## Условие задачи

Дан неориентированный невзвешенный граф с N вершинами и M рёбрами. Задана стартовая вершина S. Для каждой вершины требуется найти минимальное количество рёбер, которое нужно пройти, чтобы попасть в неё из S. Если вершина недостижима, расстояние до неё считается равным -1.

Формат ввода:
- Первая строка: три целых числа N, M, S — количество вершин, количество рёбер и стартовая вершина.
- Следующие M строк: по два целых числа u и v — концы очередного неориентированного ребра.

Формат вывода:
- N целых чисел: i-е число — длина кратчайшего пути из S в вершину i (в рёбрах), либо -1, если вершина недостижима.

Ограничения
```
· 1 ≤ N ≤ 10^5
· 0 ≤ M ≤ 2 · 10^5
· 1 ≤ S ≤ N
· Петель нет, кратные рёбра возможны.
```
---

## Идея решения

Задача — классический поиск кратчайших путей в невзвешенном графе. В таком графе длина пути измеряется количеством рёбер, и оптимальным инструментом становится обход в ширину (BFS).

Ключевое свойство BFS: вершины посещаются в порядке неубывания расстояния от стартовой. Когда мы впервые попадаем в вершину, найденное расстояние уже является минимальным — повторно её обрабатывать не нужно.

---

## Алгоритм

1. Считать N, M, S.
2. Построить список смежности: для каждого ребра (u, v) добавить v в список u и u в список v (граф неориентированный).
3. Инициализировать массив расстояний dist[1..N] значением -1 (маркер «не посещена»).
4. Установить dist[S] = 0, положить S в очередь.
5. Пока очередь не пуста:
   - извлечь вершину u;
   - для каждого соседа v:
     - если dist[v] == -1, присвоить dist[v] = dist[u] + 1 и положить v в очередь.
6. Вывести dist[1..N].

---

**Почему выбран BFS:**
- Невзвешенность графа. Все рёбра имеют одинаковый вес, поэтому алгоритмы для взвешенных графов (Дейкстра, Беллман–Форд) избыточны: их сложность выше без выигрыша в корректности.
- Оптимальность BFS. Обход в ширину гарантированно находит кратчайший путь по числу рёбер за один проход.
- Простота и надёжность. BFS легко реализуется на очереди и не требует дополнительных структур вроде приоритетной очереди.
- Обработка недостижимых вершин. Изначальное значение -1 автоматически помечает компоненты связности, не содержащие S.

---

## Оценка сложности

- Время: O(N + M) — каждая вершина попадает в очередь не более одного раза, каждое ребро просматривается один раз (дважды в списке смежности, что не меняет асимптотику).
- Память: O(N + M) — список смежности хранит 2M записей, массив расстояний занимает O(N), очередь — до O(N).

При заданных ограничениях (N ≤ 10^5, M ≤ 2·10^5) решение укладывается в лимиты с большим запасом.

---

## Особенности реализации

- Список смежности предпочтителен матрице смежности: при N = 10^5 матрица заняла бы ~10^10 ячеек, что недопустимо.
- Кратные рёбра не влияют на корректность: повторные соседи будут пропущены за счёт проверки dist[v] == -1.
- Петли в условии отсутствуют, но даже при их наличии алгоритм не сломается — вершина уже посещена и не будет добавлена повторно.
- Для ускорения ввода-вывода применяется отключение синхронизации с stdio и cin.tie(nullptr).
- Для хранения очереди используется std::queue<int> — стандартная реализация FIFO.

# Merge Sort

Описание задачи
- Необходимо реализовать сортировку массива чисел методом Merge Sort (сортировка слиянием).
- Массив должен быть отсортирован по невозрастанию — от большего значения к меньшему.
- Необходимо использовать функцию-компаратор.

Требуемая временная сложность — O(N log N).

---

Формат ввода
1. В первой строке вводится "N" — количество элементов массива.
2. В следующих "N" строках находятся числа.

---

Формат вывода
1. Вывести "N" отсортированных чисел, каждое с новой строки.

---

## Основная идея

Merge Sort использует принцип «разделяй и властвуй»:

1. Массив рекурсивно делится на две части.
2. Деление продолжается до тех пор, пока каждая часть не будет содержать один элемент.
3. Отдельные элементы считаются отсортированными.
4. Отсортированные части объединяются функцией "Merge".
5. При слиянии элементы выбираются в соответствии с компаратором.

Общая схема:
```
[исходный массив]
       ↓
  разделение
       ↓
[левая] [правая]
   ↓       ↓
разделение до
одиночных элементов
       ↓
     Merge
       ↓
[отсортированный массив]
```
---

**Функция-компаратор**
```
bool Comparator(int x, int y) {
    return x > y;
}
```
Условие "x > y" означает, что больший элемент должен находиться раньше меньшего.

Поэтому массив сортируется по невозрастанию:
```
66 > 53 > 24 > 11 > -11 > -25
```
Преимущество такого подхода заключается в том, что порядок сортировки задаётся отдельно от самого алгоритма.

Например, для сортировки по возрастанию достаточно заменить: `return x > y;` на: `return x < y;`

---

**Функция "MergeSort"**

`void MergeSort(int arr[], int left, int right)`

Функция получает массив и границы сортируемого диапазона.

Середина вычисляется: `int mid = left + (right - left) / 2;`

После этого рекурсивно сортируются обе половины:
```
MergeSort(arr, left, mid);
MergeSort(arr, mid + 1, right);
```
Когда "left == right", в диапазоне остаётся один элемент и дальнейшее деление не требуется.

После сортировки обеих частей вызывается: `Merge(arr, left, mid, right);`

---

**Функция "Merge"**

"Merge" объединяет две уже отсортированные части массива.

Сначала создаются временные массивы:
```
int* left_arr = new int[n1];
int* right_arr = new int[n2];
```
В них копируются левая и правая части исходного массива.

Затем используются три индекса:
```
int i = 0;  // левая часть
int j = 0;  // правая часть
int k = left;  // исходный массив
```
Пока в обеих частях остаются элементы, они сравниваются:
```
while (i < n1 && j < n2) {
    if (Comparator(left_arr[i], right_arr[j])) {
        arr[k] = left_arr[i];
        i++;
    } else {
        arr[k] = right_arr[j];
        j++;
    }
    k++;
}
```
При компараторе "x > y" выбирается больший элемент.

Например:
```
Левая часть:  [66, -92]
Правая часть: [24, -62]
```
Результат слияния: `[66, 24, -62, -92]`

После завершения основного цикла оставшиеся элементы одной из частей просто копируются в исходный массив:
```
while (i < n1) {
    arr[k] = left_arr[i];
    i++;
    k++;
}

while (j < n2) {
    arr[k] = right_arr[j];
    j++;
    k++;
}
```
После завершения слияния временная память освобождается:
```
delete[] left_arr;
delete[] right_arr;
```
---

Пример работы

Для массива: [66, -92, -90, 24, -62, 53, -11, 11, -25, -28] алгоритм сначала делит его на части:
```
[66, -92, -90, 24, -62]  и  [53, -11, 11, -25, -28]
```
Затем части рекурсивно делятся до отдельных элементов.

После этого начинается обратный процесс — слияние:
```
[66] + [-92] → [66, -92]

[-90] + [24] → [24, -90]

[53] + [-11] → [53, -11]

[11] + [-25] → [11, -25]
```
В результате последовательного слияния получается:
```
[66, 53, 24, 11, -11, -25, -28, -62, -90, -92]
```

## Сложность

Временная сложность — O(N log N)

1. Массив делится примерно пополам, поэтому количество уровней рекурсии составляет "log N".
2. На каждом уровне все "N" элементов участвуют в операциях слияния.

Итого: N × log N = O(N log N)

Эта сложность сохраняется для лучшего, среднего и худшего случаев.

Пространственная сложность — O(N)

Во время слияния создаются временные массивы для хранения элементов обрабатываемых частей.

Дополнительно используется стек рекурсивных вызовов глубиной "O(log N)".

Основной объём дополнительной памяти — O(N).

---

## Устойчивость

Классический Merge Sort может быть устойчивым, если при равных элементах первым выбирается элемент из левой части.

В данной реализации при равенстве: `Comparator(left_arr[i], right_arr[j])` возвращает "false", поэтому выбирается элемент из правой части.

Для массива "int" это не имеет практического значения, однако при сортировке объектов с дополнительными данными такой вариант не гарантирует сохранение исходного порядка равных элементов.

---

## Управление памятью

В программе используются динамические массивы: `int* arr = new int[n];` и временные массивы внутри "Merge".

После использования память освобождается:
```
delete[] left_arr;
delete[] right_arr;
delete[] arr;
```
Таким образом, программа не использует контейнер "std::vector" и демонстрирует ручное управление динамической памятью.

# Итог

В программе реализована сортировка Merge Sort с использованием функции-компаратора.

Основные особенности реализации:
- сортировка по невозрастанию;
- рекурсивное разделение массива;
- слияние отсортированных частей;
- функция-компаратор;

- временная сложность — O(N log N);
- дополнительная память — O(N).

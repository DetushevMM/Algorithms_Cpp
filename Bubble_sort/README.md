## Сортировка пузырьком

# Описание задачи

Необходимо отсортировать "N" целых чисел по невозрастанию, то есть от большего к меньшему.

В программе используется сортировка пузырьком (Bubble Sort).

Пример: `8 5 3 2 1`

---

Формат ввода
- В первой строке вводится число "N" — количество элементов.
- Следующие "N" строк содержат числа для сортировки.
```
Пример:

5
5
3
8
1
2
```
---

Формат вывода
- Вывести отсортированные числа, каждое с новой строки.

Для приведённого примера:
```
8
5
3
2
1
```
---

# Алгоритм

Сортировка выполняется двумя вложенными циклами.
```
for (int i = 0; i < n - 1; ++i) {
    for (int j = 0; j < n - i - 1; ++j) {
        if (arr[j] < arr[j + 1]) {
            // обмен элементов
        }
    }
}
```
- - На каждом шаге сравниваются соседние элементы.
- - Для сортировки по невозрастанию: `if (arr[j] < arr[j + 1])`
- - Если левый элемент меньше правого, они меняются местами.
- - В результате большие элементы перемещаются в начало массива, а меньшие — в конец.

Почему уменьшается диапазон внутреннего цикла?
- После каждого прохода наименьший из ещё не отсортированных элементов оказывается в конце рассматриваемой части массива.
- Поэтому следующий проход может не проверять уже отсортированные элементы: `n - i - 1`

---

Обмен элементов

Обмен выполняется через временную переменную:
```
int temp = arr[j];
arr[j] = arr[j + 1];
arr[j + 1] = temp;
```
Например: `[5, 3]`. Так как "5 < 3" — условие ложно, обмена нет.

Для: `[3, 5]`. Условие истинно, поэтому: `[5, 3]`

---

# Пошаговый пример

Исходный массив:
```
[5, 3, 8, 1, 2]
```
Проход 1

После последовательного сравнения соседних элементов:
```
[5, 8, 3, 2, 1]
```
Минимальный элемент "1" оказался в конце.

Проход 2
```
[8, 5, 3, 2, 1]
```
Элемент "2" занял своё окончательное положение.

Проход 3
```
[8, 5, 3, 2, 1]
```
Порядок уже не изменился.

Итог
```
[8, 5, 3, 2, 1]
```
Массив отсортирован по невозрастанию.

---

# Реализация

Для хранения массива используется динамическая память: `int* arr = new int[n];`

После завершения сортировки память освобождается: `delete[] arr;`

# Визуализация процесса
```
Начало:   [5, 3, 8, 1, 2]
         ↓
Проход 1: [5, 8, 3, 2, 1]  ← 1 на месте
         ↓
Проход 2: [8, 5, 3, 2, 1]  ← 2 на месте
         ↓
Проход 3: [8, 5, 3, 2, 1]  ← 3 на месте
         ↓
Проход 4: [8, 5, 3, 2, 1]  ← 5 на месте
         ↓
Конец:    [8, 5, 3, 2, 1]  ✅ Отсортировано по невозрастанию
```

# Сложность

Для "N" элементов алгоритм выполняет до "N - 1" проходов, на каждом из которых выполняется до "N" сравнений.

|Показатель| Значение|
|----------|---------|
Время| "O(N²)"
Дополнительная память| "O(1)"
Память массива| "O(N)"

Сортировка выполняется на месте: отдельный массив для результата не создаётся.

---

# Особенности реализации

- сортировка выполняется по невозрастанию;
- сравниваются соседние элементы;
- большие значения перемещаются влево;
- маленькие значения постепенно перемещаются вправо;
- после каждого прохода конец неотсортированной части становится на своё место;
- используется динамический массив без STL;
- при "N <= 0" программа завершает работу с сообщением об ошибке.

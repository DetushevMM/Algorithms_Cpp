# Обратная польская нотация (RPN)

## Описание задачи

Необходимо вычислить арифметическое выражение, записанное в обратной польской нотации (Reverse Polish Notation, RPN).
- В обычной записи оператор находится между операндами: 1 + 2
- В RPN оператор записывается после операндов: 1 2 +

Преимущество RPN заключается в том, что для определения порядка операций не нужны скобки и правила приоритета. Для решения используется структура данных стек (Stack).

---

**Формат ввода*
- В первой строке вводится "N" — количество элементов последовательности.
- В следующих "N" строках находятся целые числа или один из операторов:
```
+
-
*
:
```
Оператор ":" обозначает целочисленное деление.

Пример:
```
9
1
2
+
3
*
10
2
:
+
```
---

Формат вывода
- Вывести одно целое число — результат вычисления выражения.

Для приведённого примера: 14

---

## Основная идея

RPN обрабатывается слева направо. Для каждого элемента выполняется одно из двух действий:
```
если число:
    положить его в стек

если оператор:
    извлечь два числа из стека
    выполнить операцию
    положить результат обратно в стек
```
После обработки всех элементов в стеке остаётся единственное значение — результат выражения.

---

### Почему используется стек

Стек работает по принципу LIFO (Last In, First Out) — последним добавленный элемент извлекается первым.

Это соответствует принципу RPN: оператор использует два последних доступных операнда.

Например:
```
1
2
+
```
После чтения чисел стек: [1, 2]

При встрече "+" извлекаются:
```
b = 2
a = 1
```
Выполняется: `a + b = 1 + 2 = 3`

Результат снова помещается в стек: [3]

---

**Порядок извлечения операндов**

Для сложения и умножения порядок не имеет значения, но для вычитания и деления он критичен.
1. При встрече оператора сначала извлекается: `int b = stack.Pop();`
2. затем: `int a = stack.Pop();`

Поэтому операция выполняется как: `a - b` или: `a / b`, а не наоборот.

Например:
```
10
2
:
```
получаем:
```
b = 2
a = 10

10 / 2 = 5
```
---

### Разбор примера

Последовательность: `1 2 + 3 * 10 2 : +`

обрабатывается следующим образом:
```
1       → [1]
2       → [1, 2]
+       → [3]
3       → [3, 3]
*       → [9]
10      → [9, 10]
2       → [9, 10, 2]
:       → [9, 5]
+       → [14]
```
В конце в стеке остаётся: [14]

Следовательно, результат выражения — "14".

В обычной математической записи это выражение соответствует: `(1 + 2) * 3 + 10 / 2 = 14`

---

### Класс "Stack"

Для хранения операндов реализован собственный стек:
```
class Stack {
private:
    int* data_;
    int capacity_;
    int top_;
};
```
- "data_" — динамический массив для хранения элементов.
- "capacity_" — максимальная вместимость стека.
- "top_" — индекс верхнего элемента. Значение "-1" означает, что стек пуст.

---

**Метод "Push"**
```
void Push(int value) {
    if (top_ < capacity_ - 1) {
        data_[++top_] = value;
    }
}
```
Добавляет элемент на вершину стека.

Например: [1, 2]

после "Push(3)": [1, 2, 3]

---

**Метод "Pop"**
```
int Pop() {
    if (top_ >= 0) {
        return data_[top_--];
    }
    return 0;
}
```
Извлекает верхний элемент и уменьшает индекс вершины.

Например: [1, 2, 3]

после "Pop()":
```
вернётся 3
стек: [1, 2]
```
---

**Метод "Top"**
```
int Top() {
    if (top_ >= 0) {
        return data_[top_];
    }
    return 0;
}
```
Возвращает верхний элемент, не удаляя его.

В программе "Top()" используется после обработки всех токенов для получения окончательного результата.

---

## Обработка токенов

В основном цикле каждый элемент считывается как строка:
```
std::string token;
std::cin >> token;
```
Если строка является оператором, выполняется соответствующая операция.

Например, для сложения:
```
int b = stack.Pop();
int a = stack.Pop();
stack.Push(a + b);
```
Аналогично реализованы:
```
-  → a - b
*  → a * b
:  → a / b
```
Если токен не является оператором, он считается числом и преобразуется в "int":
```
int number = std::stoi(token);
stack.Push(number);
```
---

## Управление памятью

Стек использует динамический массив: `data_ = new int[capacity_];`

После завершения работы объекта память освобождается в деструкторе:
```
~Stack() {
    delete[] data_;
}
```
Это позволяет избежать утечки памяти.

---

### Целочисленное деление

Все операнды являются целыми числами, поэтому используется тип "int".

Оператор "/" для двух значений типа "int" выполняет целочисленное деление.

Например: 7 / 2 = 3

Дробная часть отбрасывается. Это соответствует условию задачи, согласно которому результат должен быть целым числом.

---

## Сложность

|Характеристика| Значение|
|--------------|---------|
Временная сложность| O(N)
Дополнительная память| O(N)

- Каждый токен обрабатывается один раз.
- Для каждого числа выполняется "Push", а для каждого оператора — два "Pop" и один "Push".
- В худшем случае стек может содержать до "N" элементов, поэтому требуется O(N) дополнительной памяти.

---

## Особенности реализации
- используется собственная реализация стека;
- числа и операторы обрабатываются слева направо;
- оператор извлекает два последних операнда;
- порядок "a" и "b" сохраняется для вычитания и деления;
- деление выполняется как целочисленное;
- динамическая память освобождается в деструкторе "Stack";
- алгоритм работает за O(N).

---

# Итог

Для вычисления выражения в обратной польской нотации используется стек.

Алгоритм:
```
число → Push
оператор → Pop, Pop, вычисление, Push
конец → Top
```
После обработки всей последовательности в стеке остаётся единственный элемент — результат арифметического выражения.

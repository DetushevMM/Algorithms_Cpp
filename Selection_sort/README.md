# Сортировка выбором

## Описание задачи

Необходимо реализовать сортировку массива методом выбора (Selection Sort).

Массив должен быть отсортирован по неубыванию — от меньшего значения к большему.

Основная идея алгоритма: на каждом шаге найти минимальный элемент в неотсортированной части массива и поставить его на соответствующую позицию.

---

Формат ввода
- В первой строке вводится "N" — количество чисел.
- В следующих "N" строках находятся числа.

Пример:
```
10
-82
17
-77
73
-74
-84
58
61
-5
-43
```
---

Формат вывода
- Вывести "N" отсортированных чисел, каждое с новой строки.

Для приведённого примера:
```
-84
-82
-77
-74
-43
-5
17
58
61
73
```
---

## Основная идея

Массив условно разделяется на две части:
```
[ отсортированная | неотсортированная ]
```
На каждой итерации:
1. Выбирается первый элемент неотсортированной части.
2. Предполагается, что он является минимальным.
3. В оставшейся части массива ищется элемент меньше текущего минимума.
4. Найденный минимум меняется местами с первым элементом неотсортированной части.
5. Граница отсортированной части перемещается на одну позицию вправо.

После каждой итерации один элемент занимает своё окончательное место.

---

Внешний цикл
```
for (int i = 0; i < n; ++i) {
    int minimum = i;
```
1. Индекс "i" определяет границу между уже отсортированной и ещё неотсортированной частями.
2. Перед поиском предполагается, что элемент "arr[i]" является минимальным: `int minimum = i;`
3. Затем минимум ищется среди элементов с индексами от "i + 1" до "n - 1".

---

**Поиск минимального элемента**
```
for (int j = i + 1; j < n; ++j) {
    if (arr[j] < arr[minimum]) {
        minimum = j;
    }
}
```
Если найден элемент меньше текущего минимума, сохраняется его индекс.

Например, для массива: [5, 3, 8, 1, 2] на первой итерации алгоритм сравнивает все элементы и находит "1".

---

**Обмен элементов**

После завершения поиска проверяется, находится ли минимальный элемент уже на нужной позиции:
```
if (minimum != i) {
    int temp = arr[i];
    arr[i] = arr[minimum];
    arr[minimum] = temp;
}
```
Если минимум находится в другой позиции, элементы меняются местами.

После этого:
```
[ минимальный | оставшиеся элементы ]
```
Минимальный элемент уже находится на своей окончательной позиции.

---

## Пример работы

1. Для массива: [5, 3, 8, 1, 2] первый проход находит "1": [1, 3, 8, 5, 2]
2. Следующий проход ищет минимум среди: [3, 8, 5, 2] и получает: [1, 2, 8, 5, 3]
3. Далее: [1, 2, 3, 5, 8]
4. После завершения всех проходов массив отсортирован по неубыванию.

---

**Функция "main"**

Сначала считывается количество элементов:
```
int n = 0;
std::cin >> n;
```
Затем динамически выделяется память под массив: `int* arr = new int[n];`

После чтения элементов выполняется сортировка.

В конце память освобождается: `delete[] arr;`

Таким образом, программа использует динамический массив без "std::vector".

# Сложность

|Характеристика| Значение|
|--------------|---------|
Время — лучший случай| O(N²)
Время — средний случай| O(N²)
Время — худший случай| O(N²)
Дополнительная память| O(1)
Стабильность| Да, при данной реализации

Алгоритм всегда выполняет поиск минимума в оставшейся части массива, поэтому количество сравнений имеет порядок O(N²).

При этом используется только несколько дополнительных переменных, поэтому дополнительная память составляет O(1).

---

# Особенности алгоритма
- сортировка выполняется по неубыванию;
- на каждой итерации выбирается минимальный элемент;
- используется два вложенных цикла;
- выполняется не более одного обмена на итерацию;
- сортировка выполняется непосредственно в исходном массиве;
- дополнительный массив не создаётся;
- используется ручное управление динамической памятью;
- дополнительная память — O(1).

---

# Итог

В программе реализована сортировка Selection Sort (сортировка выбором).

Основные особенности:
- поиск минимума в неотсортированной части;
- перемещение минимума на текущую позицию;
- сортировка по неубыванию;
- работа непосредственно с исходным массивом;
- временная сложность — O(N²);
- дополнительная память — O(1).

# Декартово дерево поиска (Cartesian Tree / Treap)

## Описание задачи

Необходимо реализовать декартово бинарное дерево поиска — структуру данных, которая объединяет свойства:

- бинарного дерева поиска (BST) по ключам;
- бинарной кучи (Heap) по приоритетам.

Для дерева необходимо реализовать следующие операции:

|Команда| Назначение|
|-------|-----------|
"push(elem)"| Добавить элемент в дерево
"pop(elem)"| Удалить элемент из дерева
"find(elem)"| Проверить наличие элемента
"get_min()"| Получить минимальный элемент
"get_max()"| Получить максимальный элемент

Дубликаты элементов не добавляются.

---

Формат ввода
- В первой строке находится число "N" — количество запросов к дереву.
- В следующих "N" строках находятся команды.

Примеры команд:
```
push 5
pop 3
find 5
get_min
get_max
```
Для "push" и "pop" после названия команды указывается целочисленный ключ.

---

Формат вывода

Для команд:

- "find" — выводится "TRUE" или "FALSE";
- "get_min" — выводится минимальный ключ;
- "get_max" — выводится максимальный ключ.

Команды "push" и "pop" ничего не выводят.

Если "pop" вызывается для отсутствующего элемента, дерево не изменяется.

---

## Структура декартова дерева

Каждый узел содержит:
```
struct Node {
  int key_;
  int priority_;
  Node* left_;
  Node* right_;
};
```
Где:

- "key_" — ключ элемента;
- "priority_" — случайный приоритет;
- "left_" — указатель на левое поддерево;
- "right_" — указатель на правое поддерево.

Дерево одновременно поддерживает два свойства.

1. Свойство бинарного дерева поиска

Для каждого узла:
- ключи левого поддерева < key
- ключи правого поддерева > key

Поэтому поиск элемента выполняется так же, как в обычном BST.

2. Свойство кучи

Для каждого узла приоритет родителя не меньше приоритетов его потомков:
```
priority(parent) >= priority(child)
```
В реализации используется максимальная куча:
```
if (left->priority_ > right->priority_)
```
Узел с большим приоритетом располагается выше.

---

Основные алгоритмы
- Split — разделение дерева
- "Split" разделяет дерево по заданному ключу на два дерева:
```
left  — ключи < key
right — ключи >= key
```
Реализация:
```
void Split(Node* node, int key, Node*& left, Node*& right) {
  if (node == nullptr) {
    left = nullptr;
    right = nullptr;
    return;
  }

  if (node->key_ < key) {
    Split(node->right_, key, node->right_, right);
    left = node;
  } else {
    Split(node->left_, key, left, node->left_);
    right = node;
  }
}
```
Принцип работы

Если: `node->key_ < key`, то текущий узел должен находиться в "left".

Его левое поддерево также полностью относится к "left", поэтому необходимо разделить только правое поддерево.
```
        node
       /    \
      L      R

             Split(R, key)
                 /      \
              R_left   R_right

        node
       /    \
      L    R_left

left = node
right = R_right
```
Если: `node->key_ >= key` происходит симметричная операция: текущий узел отправляется в "right", а разделяется левое поддерево.

Сложность O(h), где "h" — высота дерева.

Для сбалансированного декартова дерева: `O(log n) в среднем.`

---

**Merge — слияние деревьев**

"Merge" объединяет два дерева:

left  — все ключи меньше
right — все ключи больше
```
Node* Merge(Node* left, Node* right) {
  if (left == nullptr) {
    return right;
  }

  if (right == nullptr) {
    return left;
  }

  if (left->priority_ > right->priority_) {
    left->right_ = Merge(left->right_, right);
    return left;
  } else {
    right->left_ = Merge(left, right->left_);
    return right;
  }
}
```
Принцип работы

Сравниваются приоритеты корней двух деревьев.

Если: `left->priority_ > right->priority_`
- корнем объединённого дерева становится "left".
-  Его правое поддерево объединяется с "right".
- Если приоритет "right" больше, корнем становится "right".

Таким образом одновременно сохраняются:

- порядок ключей BST;
- свойство кучи.

Сложность `O(h)`

или в среднем: `O(log n)`

---

**Push — добавление элемента**
```
Алгоритм вставки:
void Push(int key) {
  if (Find(root_, key)) {
    return;
  }

  int priority = std::rand();
  Node* new_node = new Node(key, priority);

  Node* left;
  Node* right;

  Split(root_, key, left, right);
  root_ = Merge(Merge(left, new_node), right);
}
```
**Шаг 1. Проверка дубликата**

Сначала выполняется: `Find(root_, key)`

Если такой ключ уже существует, новый узел не создаётся.

**Шаг 2. Создание узла**

Для нового элемента генерируется случайный приоритет: `int priority = std::rand();`

**Шаг 3. Разделение дерева**

Исходное дерево разделяется:
```
left  — ключи < key
right — ключи >= key
```
**Шаг 4. Вставка нового узла**

Получаются три части: `left + new_node + right`

Они объединяются двумя операциями "Merge": `root_ = Merge(Merge(left, new_node), right);`

Так сохраняются оба свойства декартова дерева.

**Сложность**

В среднем: `O(log n)`

В худшем случае: `O(n)`

---

**Pop — удаление элемента**

Удаление выполняется с помощью двух операций "Split".
```
void Pop(int key) {
  if (!Find(root_, key)) {
    return;
  }

  Node* left;
  Node* right;
  Node* mid;

  Split(root_, key, left, right);
  Split(right, key + 1, mid, right);

  DestroyTree(mid);

  root_ = Merge(left, right);
}
```
Первый Split
```
Split(root_, key, left, right);
```
Получаем:
```
left  — ключи < key
right — ключи >= key
```
Второй Split
```
Split(right, key + 1, mid, right);
```
Так как ключи являются целыми числами: `key <= x < key + 1`

может выполняться только для: `x == key`

Поэтому:
```
mid — элемент с ключом key
right — ключи > key
```
Поскольку дубликаты запрещены, "mid" содержит только один узел.

**Удаление**

Поддерево "mid" удаляется: `DestroyTree(mid);`

После этого остаются:
```
left       right
```
Они объединяются: `root_ = Merge(left, right);`

Сложность

В среднем: `O(log n)`

В худшем случае: `O(n)`

---

**Find — поиск элемента**

Поиск реализован как обычный поиск в бинарном дереве поиска:
```
bool Find(Node* node, int key) {
  if (node == nullptr) {
    return false;
  }

  if (node->key_ == key) {
    return true;
  }

  if (key < node->key_) {
    return Find(node->left_, key);
  }

  return Find(node->right_, key);
}
```
Алгоритм:

1. Если узел отсутствует — элемента нет.
2. Если ключ совпадает — элемент найден.
3. Если искомый ключ меньше текущего — переход влево.
4. Если больше — переход вправо.

Сложность

В среднем: `O(log n)`

В худшем случае: `O(n)`

---

**GetMin — поиск минимального элемента**

В BST минимальный элемент находится в самом левом узле.
```
Node* FindMin(Node* node) {
  if (node == nullptr) {
    return nullptr;
  }

  while (node->left_ != nullptr) {
    node = node->left_;
  }

  return node;
}
```
Алгоритм последовательно переходит:
```
root
  ↓
left
  ↓
left
  ↓
...
```
Пока не будет достигнут узел без левого потомка.

**Сложность**

В среднем: `O(log n)`

В худшем случае: `O(n)`

---

GetMax — поиск максимального элемента

Максимальный элемент находится в самом правом узле.
```
Node* FindMax(Node* node) {
  if (node == nullptr) {
    return nullptr;
  }

  while (node->right_ != nullptr) {
    node = node->right_;
  }

  return node;
}
```
Алгоритм последовательно переходит вправо до последнего узла.

Сложность

В среднем: `O(log n)`

В худшем случае: `O(n)`

---

**DestroyTree — освобождение памяти**

Для удаления дерева используется рекурсивный обход:
```
void DestroyTree(Node* node) {
  if (node != nullptr) {
    DestroyTree(node->left_);
    DestroyTree(node->right_);
    delete node;
  }
}
```
Сначала удаляются потомки, затем сам узел.

Это необходимо, поскольку узлы создаются динамически:

new Node(...)

и должны быть освобождены: `delete node;`

Метод используется:

- в деструкторе "DecartTree";
- при удалении элемента через "Pop".

---

Случайные приоритеты

При добавлении каждого нового узла используется: `int priority = std::rand();`

Перед началом работы программы устанавливается фиксированное начальное значение генератора: `std::srand(12345);`

Это делает последовательность генерируемых приоритетов воспроизводимой при повторных запусках программы.

Случайные приоритеты нужны для поддержания ожидаемой сбалансированности дерева.
```
Например, если приоритеты будут зависеть от ключей монотонно:
key:      1  2  3  4  5
priority: 1  2  3  4  5
```
дерево может выродиться:
```
1
 \
  2
   \
    3
     \
      4
       \
        5
```
Высота такого дерева равна "n", поэтому операции могут выполняться за "O(n)".

При случайных приоритетах декартово дерево имеет ожидаемую высоту порядка "O(log n)".

## Обработка команд

В "main()" команды читаются в массив:

char command[20];
std::cin >> command;

Для определения команды используются отдельные символы.
```
"push"

command[0] == 'p' && command[1] == 'u'

"pop"

command[0] == 'p' && command[1] == 'o'

"find"

command[0] == 'f'

"get_min"

command[0] == 'g' && command[6] == 'n'

"get_max"

command[0] == 'g' && command[6] == 'x'
```
Для строки: `get_min` индексы символов:
```
g e t _ m i n
0 1 2 3 4 5 6
```
Поэтому "command[6] == 'n'" определяет "get_min", а "command[6] == 'x'" — "get_max".

Такой способ разбора не использует "std::string" и контейнеры STL.

Итоговая сложность

Пусть "n" — количество элементов в дереве, а "h" — его высота.

|Операция| Средний случай| Худший случай|
|--------|---------------|--------------|
"push"| "O(log n)"| "O(n)"
"pop"| "O(log n)"| "O(n)"
"find"| "O(log n)"| "O(n)"
"get_min"| "O(log n)"| "O(n)"
"get_max"| "O(log n)"| "O(n)"
"Split"| "O(log n)"| "O(n)"
"Merge"| "O(log n)"| "O(n)"
"DestroyTree"| "O(n)"| "O(n)"

Память: `O(n)`

Каждый элемент хранится в одном узле дерева.

## Почему алгоритм работает

Декартово дерево поддерживает одновременно два свойства:
```
BST по key_
Heap по priority_
``
За счёт свойства BST можно эффективно выполнять:
```
find
get_min
get_max
```
За счёт "Split" и "Merge" удобно реализуются:
```
push
pop
```
Случайные приоритеты позволяют поддерживать небольшую высоту дерева в среднем.
```
Основная идея реализации:

                 Treap
                   │
          ┌────────┴────────┐
          │                 │
         BST               Heap
       по key            по priority
          │                 │
          └────────┬────────┘
                   │
             Split + Merge
                   │
          ┌────────┴────────┐
          │                 │
        Push               Pop
```
Таким образом, две базовые операции — "Split" и "Merge" — являются основой всей реализации декартова дерева.

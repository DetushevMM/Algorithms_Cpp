# Динамический массив

## Описание задачи

Необходимо реализовать собственный класс динамического массива, аналогичный по базовому принципу работы стандартному контейнеру "std::vector".

Массив должен автоматически увеличивать выделенную память при заполнении текущей ёмкости.

Необходимо реализовать следующие операции:

|Метод| Назначение|
|-----|-----------|
"push_back(element)"| Добавить элемент в конец массива
"pop_back()"| Удалить последний элемент и вернуть его значение
"size()"| Получить текущее количество элементов
"capacity()"| Получить текущую вместимость массива
"operator[]"| Получить или изменить элемент по индексу

Главное требование к "push_back" — амортизированная сложность O(1).

---

## Принцип работы

Динамический массив состоит из трёх основных переменных:
```
int* data_;
int size_;
int capacity_;

"data_"
```
Указатель на область динамической памяти, в которой хранятся элементы. `"size_"` - Количество элементов, которые фактически находятся в массиве.

Количество элементов, для которых уже выделена память - `"capacity_"`.

Например:
```
size = 3
capacity = 4

data:
┌────┬────┬────┬────┐
│ 10 │ 20 │ 30 │    │
└────┴────┴────┴────┘
  ↑     ↑        ↑
элементы      свободная
              ячейка

Здесь:

size     = 3
capacity = 4
```
---

**Размер и вместимость**

Очень важно различать "size" и "capacity".

Size - показывает, сколько элементов реально находится в массиве.

Capacity - показывает, сколько элементов можно разместить без нового выделения памяти.

Например:
```
data:
┌────┬────┬────┬────┬────┬────┬────┬────┐
│ 10 │ 20 │ 30 │ 40 │    │    │    │    │
└────┴────┴────┴────┴────┴────┴────┴────┘

size = 4
capacity = 8
```
Следующие четыре "push_back" могут выполняться без расширения памяти.

---

**Конструктор**
```
DynamicArray()
    : data_(nullptr), size_(0), capacity_(0) {}

При создании массива:

data_     = nullptr
size_     = 0
capacity_ = 0
```
Память заранее не выделяется.

Это означает, что пустой "DynamicArray" не занимает память под элементы.

---

**PushBack — добавление элемента**

Основной метод:
```
void PushBack(int elem) {
  if (size_ >= capacity_) {
    Resize();
  }

  data_[size_] = elem;
  size_++;
}
```
Алгоритм:

1. Проверяем, есть ли свободное место.
2. Если места нет — увеличиваем массив.
3. Записываем новый элемент в первую свободную ячейку.
4. Увеличиваем "size_".

Например:

До:
```
size = 3
capacity = 4

[10][20][30][  ]
             ↑
         свободное место

Выполняется:

PushBack(40);

Получаем:

size = 4
capacity = 4

[10][20][30][40]
```
Следующий "PushBack" уже потребует расширения.

---

**Resize — увеличение массива**

Метод "Resize()" отвечает за выделение нового блока памяти:
```
void Resize() {
  int new_capacity = (capacity_ == 0) ? 1 : capacity_ * 2;

  int* new_data = new int[new_capacity];

  for (int i = 0; i < size_; ++i) {
    new_data[i] = data_[i];
  }

  delete[] data_;

  data_ = new_data;
  capacity_ = new_capacity;
}
```
Размер массива увеличивается в два раза:
```
0 → 1 → 2 → 4 → 8 → 16 → 32 → ...
```
---

***Пошаговая работа Resize***

Предположим, сейчас:
```
size = 4
capacity = 4
```
Массив:

[10][20][30][40]

Добавляется ещё один элемент.

Свободного места нет, поэтому вызывается "Resize()".

Шаг 1. Вычисляем новую вместимость

new_capacity = capacity_ * 2;

Получаем:

new_capacity = 8

Шаг 2. Выделяем новый массив

int* new_data = new int[8];

Шаг 3. Копируем элементы

Старый массив:

[10][20][30][40]

Новый массив:

[10][20][30][40][ ][ ][ ][ ]

Шаг 4. Освобождаем старую память

delete[] data_;

Шаг 5. Перенаправляем указатель

data_ = new_data;
capacity_ = 8;

Теперь можно добавить новый элемент:

[10][20][30][40][50][ ][ ][ ]

---

Почему PushBack работает амортизированно за O(1)

Отдельная операция расширения может занимать "O(n)", потому что при "Resize()" приходится копировать все существующие элементы.

Например:
```
push 1 → capacity 1
push 2 → capacity 2, копируем 1 элемент
push 3 → capacity 4, копируем 2 элемента
push 4 → места хватает
push 5 → capacity 8, копируем 4 элемента
push 6 → места хватает
push 7 → места хватает
push 8 → места хватает

if (command == "push_back") {
  int value = 0;
  std::cin >> value;
  arr.PushBack(value);
}
```
Сначала считывается число, затем оно добавляется в конец массива.
```
"pop_back"

else if (command == "pop_back") {
  std::cout << arr.PopBack() << '\n';
}
```
Удаляется последний элемент и выводится его значение.
```
"size"

else if (command == "size") {
  std::cout << arr.Size() << '\n';
}
```
Выводится количество элементов.
```
"index"

else if (command == "index") {
  int index = 0;
  std::cin >> index;
  std::cout << arr[index] << '\n';
}
```
Считывается индекс и выводится соответствующий элемент.

## Сложность операций

|Операция| Время| Дополнительная память|
|--------|------|----------------------|
"push_back"| O(1) амортизированно| O(1)
"push_back" при Resize| O(n)| O(n) временно
"pop_back"| O(1)| O(1)
"size"| O(1)| O(1)
"capacity"| O(1)| O(1)
"operator[]"| O(1)| O(1)
"Resize"| O(n)| O(n)
деструктор| O(n)| O(1)

Основное преимущество динамического массива заключается в том, что дорогая операция "Resize" выполняется редко.

---

Инварианты структуры

Для корректной работы класса всегда выполняются следующие условия: `0 <= size_ <= capacity_`

Если: `size_ < capacity_`, то следующий "push_back" может добавить элемент без выделения новой памяти.

Если: `size_ == capacity_`, то перед добавлением необходимо вызвать "Resize()".

После "Resize":
```
new_capacity = 1                  при capacity_ == 0
new_capacity = capacity_ * 2      иначе
```

## Особенности реализации

1. Начальная вместимость равна 0
```
data_ = nullptr;
size_ = 0;
capacity_ = 0;
```
Память выделяется только при первой вставке.

2. Вместимость увеличивается в два раза
```
1 → 2 → 4 → 8 → 16 → ...
```
Это позволяет получить амортизированную сложность "O(1)" для "push_back".

3. После "pop_back" память не освобождается

Изменяется только:
```
size_--;

"capacity_" остаётся прежним.
```
4. Индекс не проверяется

Оператор: arr[index] не проверяет:
```
0 <= index < size
```
Это соответствует поведению обычного встроенного массива C++: ответственность за корректность индекса лежит на вызывающем коде.

5. Реализация не использует "std::vector"

Динамическая память управляется вручную через:
```
new[]
delete[]
```
Это позволяет на практике понять внутренний принцип работы динамического массива.

# Итог
```
Данный класс реализует базовый механизм динамического массива:

              DynamicArray
                   │
        ┌──────────┼──────────┐
        │          │          │
      data_      size_    capacity_
        │          │          │
        │          │          │
        └──────┬───┴──────────┘
               │
          push_back
               │
        capacity закончилась?
          /            \
        нет             да
        │               │
        │            Resize()
        │               │
        └───────┬───────┘
                │
           добавить
           элемент
```
Главный алгоритмический приём — удвоение capacity при заполнении массива.

Благодаря этому:
```
push_back  → O(1) амортизированно
pop_back   → O(1)
size       → O(1)
capacity   → O(1)
operator[] → O(1)
```
Таким образом, реализация демонстрирует основные принципы работы динамических массивов и является упрощённой моделью контейнера "std::vector".

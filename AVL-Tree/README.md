## AVL-дерево на C++

# Описание задачи

Реализовать самобалансирующееся бинарное дерево поиска AVL без использования STL-контейнеров.

Дерево должно поддерживать следующие операции:
- "push X" — добавить элемент "X";
- "pop X" — удалить элемент "X";
- "find X" — проверить наличие элемента "X";
- "get_min" — получить минимальный элемент;
- "get_max" — получить максимальный элемент.

Дубликаты элементов не добавляются.

Формат входных данных
- В первой строке вводится число "N" — количество команд.
- Следующие "N" строк содержат команды:
```
- push X
- pop X
- find X
- get_min
- get_max
```
Формат выходных данных

Для команды "find" выводится:
- TRUE, если элемент найден, и
- FALSE, если элемента нет.

Для "get_min" и "get_max" выводится соответствующее значение.

## Что такое AVL-дерево

AVL-дерево — это самобалансирующееся бинарное дерево поиска (BST).

Для каждого узла выполняются два условия:

1. Все элементы левого поддерева меньше ключа узла.
2. Все элементы правого поддерева больше ключа узла.
3. Разница высот левого и правого поддеревьев по модулю не превышает "1".

Баланс-фактор узла вычисляется по формуле:

BF = height(left) - height(right)

Возможные состояния:
```
BF = -1   сбалансировано
BF =  0   сбалансировано
BF = +1   сбалансировано
```
Если: BF > 1 или BF < -1 узел необходимо сбалансировать с помощью поворотов.

Благодаря балансировке высота AVL-дерева остаётся "O(log N)".

---

Структура узла

Каждый узел хранит:

- ключ;
- указатель на левого потомка;
- указатель на правого потомка;
- высоту поддерева.

Упрощённо структура выглядит так:
```
struct Node {
    int key_;
    int height_;
    Node* left_;
    Node* right_;
};
```
Высота пустого поддерева считается равной "0", высота листа — "1".

---

# Алгоритм балансировки

После изменения дерева вызывается функция: Node* Balance(Node* n)

Она:

1. пересчитывает высоту узла;
2. вычисляет баланс-фактор;
3. определяет тип дисбаланса;
4. выполняет необходимый поворот;
5. возвращает новый корень поддерева.

UpdateHeight(n);
int bf = BalanceFactor(n);

Если: bf > 1 - дерево перегружено слева.

Если: bf < -1 - дерево перегружено справа.

# Повороты

Поворот — локальная перестройка нескольких связей между узлами.

При этом порядок элементов бинарного дерева поиска сохраняется.

Поворот выполняется за "O(1)".

Правый поворот

Используется при левом дисбалансе.

До:

        y
       / \
      x   C
     / \
    A   B

После:

        x
       / \
      A   y
         / \
        B   C

Реализация:
```
Node* RotateRight(Node* y) {
    Node* x = y->left_;
    Node* T2 = x->right_;

    x->right_ = y;
    y->left_ = T2;

    UpdateHeight(y);
    UpdateHeight(x);

    return x;
}
```
---

Левый поворот

Используется при правом дисбалансе.

До:

      x
     / \
    A   y
       / \
      B   C

После:

        y
       / \
      x   C
     / \
    A   B

Левый поворот является зеркальным отражением правого.

---

Четыре случая дисбаланса

AVL-дерево имеет четыре основных случая.

Случай| Дисбаланс| Действие
Left-Left| левое поддерево перегружено слева| правый поворот
Left-Right| левое поддерево перегружено справа| левый поворот ребёнка + правый поворот
Right-Right| правое поддерево перегружено справа| левый поворот
Right-Left| правое поддерево перегружено слева| правый поворот ребёнка + левый поворот

В коде:
```
if (bf > 1) {
    if (BalanceFactor(n->left_) < 0) {
        n->left_ = RotateLeft(n->left_);
    }
    return RotateRight(n);
}

if (bf < -1) {
    if (BalanceFactor(n->right_) > 0) {
        n->right_ = RotateRight(n->right_);
    }
    return RotateLeft(n);
}
```
---

Вставка — "push"

Алгоритм вставки основан на обычной вставке в бинарное дерево поиска.

Node* Insert(Node* n, int key)

Алгоритм1. Если текущий узел отсутствует, создаётся новый узел.
2. Если ключ меньше текущего — поиск продолжается слева.
3. Если ключ больше текущего — поиск продолжается справа.
4. Если ключ уже существует — новый узел не создаётся.
5. После возврата из рекурсии выполняется балансировка.

Схематично:

             Insert
                |
                v
       обычная вставка BST
                |
                v
        возврат по рекурсии
                |
                v
       UpdateHeight()
                |
                v
          Balance()
                |
                v
         возможно поворот

Почему балансировка выполняется после рекурсии?

Новый узел добавляется в нижней части дерева.

Поэтому сначала изменяется высота нижнего узла, затем его родителя, затем родителя родителя и так далее до корня.

Именно поэтому балансировка выполняется при возврате из рекурсивного вызова.

Сложность O(log N)

---

Удаление — "pop"

Удаление является более сложной операцией. В обычном бинарном дереве поиска возможны три ситуации.

1. Узел — лист

У узла нет потомков.

Он просто удаляется:

    X

    ↓

   null

2. Есть один потомок

Удаляемый узел заменяется своим потомком:

    X
     \
      Y

    ↓

    Y

3. Есть два потомка

Используется следующий по величине элемент — минимальный элемент правого поддерева.

Например:

          50
         /  \
       30    70
            /  \
           60   80

При удалении "50" выбирается "60".

Получается:

          60
         /  \
       30    70
               \
                80

В коде:
```
Node* minNode = FindMin(right);
minNode->right_ = RemoveMin(right);
minNode->left_ = left;
return Balance(minNode);
```
После удаления балансировка выполняется на каждом уровне рекурсии.

Это важно, поскольку удаление может уменьшить высоту поддерева и вызвать дисбаланс не только у непосредственного родителя, но и выше по дереву.

Сложность O(log N)

---

Поиск — "find"

Поиск использует свойство бинарного дерева поиска.
- Если: key < node->key_ поиск продолжается в левом поддереве.
- Если: key > node->key_ поиск продолжается в правом поддереве.
- Если значения равны — элемент найден.

Реализация использует цикл:
```
while (n) {
    if (key == n->key_) {
        return true;
    } else if (key < n->key_) {
        n = n->left_;
    } else {
        n = n->right_;
    }
}
```
В отличие от "Insert" и "Remove", поиск реализован без рекурсии.

Сложность O(log N)

---

Поиск минимума — "get_min"

В бинарном дереве поиска минимальный элемент находится в самом левом узле.

Поэтому нужно двигаться только по левым указателям:

          50
         /
        30
       /
      10

Минимум:

10

Алгоритм:
```
while (n->left_) {
    n = n->left_;
}
```
Сложность O(log N)

---

Поиск максимума — "get_max"

Максимальный элемент находится в самом правом узле.

Например:

    50
      \
       70
         \
          90

Максимум: 90

Алгоритм аналогичен поиску минимума, но используется правый указатель:
```
while (n->right_) {
    n = n->right_;
}
```
Сложность O(log N)

---

Удаление минимального элемента

Вспомогательная функция: Node* RemoveMin(Node* n) используется при удалении узла с двумя детьми.

Она идёт влево до самого минимального элемента.

Если минимальный узел найден:
```
if (!n->left_) {
    return n->right_;
}
```
его правое поддерево поднимается на место удалённого узла.

После этого выполняется балансировка: return Balance(n);

---

Управление памятью

Дерево динамически создаёт узлы: new Node(key)

При удалении узла используется: delete n;

Для освобождения всех узлов дерева реализована функция: void Destroy(Node* n)

Она рекурсивно удаляет:

1. левое поддерево;
2. правое поддерево;
3. текущий узел.

Деструктор класса:
```
~AVLTree() {
    Destroy(root_);
}
```
гарантирует освобождение памяти при уничтожении объекта "AVLTree".

# Сложность алгоритмов

Поскольку AVL-дерево сохраняет логарифмическую высоту, основные операции выполняются за "O(log N)".

| Операция| Временная сложность| Дополнительная память|
|---------|-------------------|-----------------------|
"push"| "O(log N)"| "O(log N)" на рекурсию
"pop"| "O(log N)"| "O(log N)" на рекурсию
"find"| "O(log N)"| "O(1)"
"get_min"| "O(log N)"| "O(1)"
"get_max"| "O(log N)"| "O(1)"
"RotateLeft"| "O(1)"| "O(1)"
"RotateRight"| "O(1)"| "O(1)"
"Balance"| "O(1)"| "O(1)"
"Destroy"| "O(N)"| "O(log N)" на стек рекурсии

Общий объём памяти, занимаемый деревом: O(N)

---

Почему AVL-дерево сохраняет "O(log N)"

Обычное бинарное дерево поиска не гарантирует логарифмическую высоту.

Например, если последовательно добавить:
```
10
20
30
40
50
```
обычное BST может превратиться практически в список:

10
  \
   20
     \
      30
        \
         40
           \
            50

Высота становится "O(N)".

AVL-дерево после каждой операции контролирует баланс и выполняет повороты:
```
       30
      /  \
    20    40
   /        \
 10          50
```
Поэтому высота дерева остаётся логарифмической.

Для AVL-дерева справедливо ограничение: h = O(log N)

Более точная оценка высоты имеет вид приблизительно: h ≤ 1.44 · log₂(N)

Следовательно, поиск, вставка и удаление имеют гарантированную логарифмическую сложность.

# Итог

В программе реализовано полноценное AVL-дерево без использования STL-контейнеров.

Поддерживаются:

- push X
- pop X
- find X
- get_min
- get_max

Основные алгоритмические элементы:

- бинарное дерево поиска;
- хранение высоты узлов;
- вычисление balance factor;
- левый и правый повороты;
- двойные повороты;
- рекурсивная вставка;
- рекурсивное удаление;
- удаление минимального элемента;
- поиск элемента;
- поиск минимума и максимума;
- автоматическое освобождение динамической памяти.

Главное преимущество реализации — гарантированная "O(log N)" высота дерева, благодаря чему основные операции не деградируют до "O(N)", как это может произойти в обычном бинарном дереве поиска.Для учебного репозитория этот README уже можно использовать как основной документ к задаче.
